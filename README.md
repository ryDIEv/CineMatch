# CineMatch

CineMatch — ИИ-ассистент для выбора фильма на вечер. Он помогает сократить время на поиск до нескольких минут, учитывая настроение пользователя, доступное время, город, погоду и историю оценок.

Проект строится как агентная система: модель не выбирает фильмы напрямую, а формирует критерии и задаёт вопросы, а конкретные кандидаты возвращаются из локальной базы данных. Это позволяет получить релевантные рекомендации без «галлюцинаций» и без подмены реальных фильмов.

## Ключевая идея

Выбор фильма часто занимает гораздо больше времени, чем ожидалось: каталог большой, фильтры неудобные, а важные факторы вроде усталости, погоды, минуты до сна и личных предпочтений обычно не учитываются.

CineMatch решает эту задачу так:

1. Пользователь отвечает на короткий набор вопросов.
2. Система учитывает историю оценок и текущие условия.
3. Агент-рекомендатель формирует критерии поиска.
4. База данных возвращает релевантные фильмы.
5. Пользователь получает три варианта с пояснениями.
6. После просмотра система собирает обратную связь и улучшает следующие рекомендации.

Цель проекта — уменьшить время выбора фильма до порядка одной минуты.

## Принципы архитектуры

Проект реализован в соответствии с vision-документами и строится на нескольких принципах:

- Агентный подход: решения о следующем шаге принимает языковая модель через инструменты и function calling.
- Фильмы выбирает база данных, а не LLM: модель формирует критерии, а данные берутся из локального каталога.
- Модульность: данные, агенты и интерфейс работают независимо и общаются через контракты.
- Открытые источники данных: каталог — TMDB, погода — Open-Meteo.
- Один сценарий, два интерфейса: консоль и Telegram-бот используют одно и то же ядро.

## Как работает система

### Основной сценарий

1. Пользователь запускает CineMatch в консоли или Telegram.
2. Если есть ранее выбранный, но не оценённый фильм, сначала спрашивают, как он прошёл.
3. Агент-распознаватель состояния задаёт базовые вопросы: настроение, свободное время, пожелания, город.
4. Система запрашивает историю оценок и погоду.
5. Агент-рекомендатель формирует поисковые критерии.
6. Из локальной базы данных выбираются кандидаты.
7. Пользователь получает три фильма с кратким объяснением почему они подошли.
8. Он может выбрать фильм, попросить ещё варианты или пересобрать подборку.
9. После просмотра проводится короткий опрос и сохраняется оценка.

## Архитектура проекта

Проект разделён на три ключевых модуля.

### 1. Модуль данных

Отвечает за хранение и получение данных:

- локальная SQLite-база `database.db`
- загрузка каталога фильмов из TMDB
- получение погоды из Open-Meteo
- функции для работы с историей оценок, профилем пользователя и состоянием сессии

Этот модуль не содержит логику рекомендаций и не отвечает за интерфейс. Он работает с данными и даёт инструментам доступ к нужным функциям.

### 2. Модуль ИИ-агентов

Содержит оркестратор и три агента:

- Агент-распознаватель состояния
- Агент-рекомендатель
- Агент-компаньон

Оркестратор маршрутизирует диалог, сохраняет состояние сессии и передаёт сообщения нужному агенту. Каждый агент работает со своим набором инструментов и системой промптов.

### 3. Модуль интерфейса

Поддерживает пользовательский сценарий через:

- консольное приложение
- Telegram-бот

Интерфейс не принимает решения о логике рекомендаций — он только передаёт ввод пользователя в ядро и показывает возвращённый ответ.

## Основные сущности

- user_id — идентификатор пользователя
- session state — текущее состояние диалога
- state vector — структурированное описание настроения, времени, погоды, пожеланий
- candidate list — список фильмов, выбранных на текущий подбор
- pending feedback — выбранный, но ещё не оценённый фильм

## Требования и ограничения

### Функциональные требования

- Загрузка каталога фильмов с жанрами, рейтингом, длительностью, годом и актёрами
- Определение состояния пользователя через короткий диалог
- Учет истории оценок и личных предпочтений
- Выдача 3 фильмов с объяснением выбора
- Поддержка вариантов действий: выбрать фильм, показать ещё варианты, пересобрать подборку
- Сбор оценки после просмотра
- Работа одинаково в консоли и Telegram

### Нефункциональные требования

- Время полного подбора — порядка 1 минуты
- Модульность и контрактное взаимодействие между компонентами
- Устойчивость к ошибкам внешних сервисов
- Безопасность диалога и проверка структурированных ответов модели
- Хранение API-ключей в `.env`, а не в репозитории

## Технологический стек

- Python — основа модулей агента и утилит
- SQLite — локальное хранилище данных
- TMDB API — каталог фильмов
- Open-Meteo — погодные данные
- Telegram Bot API — интерфейс пользователя
- LLM / SLM — генерация решений и формирование критериев поиска

## Этапы развития

Согласно vision-проекту, развитие идёт по этапам:

1. MVP: консольный интерфейс, внешний LLM API, подборка фильмов и оценка
2. Telegram-бот: тот же сценарий в чате
3. Локальные модели: работа с SLM/LLM локально
4. Сериалы и напоминания: добавление сериалов, отслеживание прогресса и уведомления

## Коротко

CineMatch — это не просто рекомендационный сервис с каталогом. Это диалоговый ИИ-ассистент, который помогает выбрать фильм по обстоятельствам, быстро и без перегруза. Его цель — сделать подбор фильма коротким, персональным и понятным.
