# CineMatch

Веб-приложение с ИИ-агентом, которое помогает выбрать фильм на вечер. Пользователь пишет своими словами, как прошёл день и сколько у него времени, а CineMatch учитывает его настроение, погоду и историю оценок и предлагает три фильма. К каждому фильму прилагается объяснение, почему он подходит.

> **Статус:** идёт проектирование, готовы vision и проектная документация. Код MVP пишется с ноября 2026 г. Сроки по этапам приведены в разделе [«Этапы»](#этапы).

## Ключевые возможности

1. **Подбор в диалоге.** Агент переводит настроение, свободное время, компанию, пожелания, погоду и историю оценок в три фильма. Каждый показан с постером, возрастной маркировкой и объяснением выбора.
2. **Ответ своими словами.** Пользователь может написать «беру второй», «давай посмешнее» или «в другой раз», и агент сам поймёт, что имеется в виду. Фильм можно выбрать и нажатием на карточку.
3. **Прозрачность решений.** Под каждой подборкой видно, какие данные агент смотрел и по каким критериям искал.
4. **Оценки и история.** При следующем визите CineMatch спрашивает, как прошёл выбранный фильм. Просмотренное без CineMatch можно отметить фразой «посмотрел X, на 8 из 10».
5. **Только реальные фильмы.** Модель задаёт критерии поиска, а сами фильмы берутся из локального каталога, загруженного из TMDB.
6. **Бережное отношение к данным.** Перед началом работы приложение запрашивает согласие. Данные хранятся только локально и удаляются одной командой.
7. **Запуск одной командой:** `docker compose up`.

## Архитектура

```
Браузер ──► Веб-интерфейс (React, nginx) ──► API (FastAPI) ──► Модуль ИИ-агентов ──► RouterAI (LLM)
                                                          └──► Модуль данных ──► SQLite, TMDB, Open-Meteo
```

Агентом в проекте называется компонент, в котором языковая модель сама выбирает следующее действие и вызывает инструменты (tool use). Оркестратор диалога — обычный код: он отвечает за согласие, удаление данных, лимиты и проверку ответа. Внутри разговора решения принимает агент CineMatch: сам выбирает инструменты, ищет фильмы в каталоге и объясняет выбор.

| Модуль | Состав | Документация |
|---|---|---|
| ИИ-агенты | Оркестратор, классификатор запросов, агент CineMatch, промпты, инструменты | [documents/agents](documents/agents/README.md) |
| Данные | SQLite, загрузка каталога из TMDB, погода, функции-инструменты для агента | [documents/data](documents/data/README.md) |
| Интерфейс | Веб-приложение, REST API с потоковыми ответами, Docker Compose | [documents/ui](documents/ui/README.md) |

За каждый модуль отвечает один участник команды: он реализует модуль и ведёт его документацию.

## Технологии

| Область | Выбор | Почему |
|---|---|---|
| Бэкенд | Python 3.14, uv | Основной язык экосистемы LLM; актуальная версия с поддержкой до 2030 года |
| API | FastAPI, Server-Sent Events | Асинхронность, типизированные контракты, потоковый вывод хода работы агента |
| Интерфейс | React, TypeScript, Vite | Типы общие с контрактом API, быстрая сборка |
| Языковая модель | RouterAI | Один API к разным моделям с оплатой из России; модель меняется без изменения кода |
| Агент | Pydantic AI | Типизированные инструменты, ответ по схеме, лимиты, те же модели Pydantic, что и в FastAPI |
| Хранилище | SQLite (WAL), SQLAlchemy 2.0 | Один файл и никакого сервера, этого достаточно для локального запуска |
| Каталог фильмов | TMDB API | Описания и постеры на русском, состав съёмочной группы, возрастные рейтинги |
| Погода | Open-Meteo | Бесплатный API без ключа, есть геокодирование городов |
| Развёртывание | Docker Compose | Одинаковое окружение у всех участников и на демонстрации |
| Разработка | GitHub flow, Spec Kit, OpenCode | Короткие ветки с ревью, спецификация до кода, единый ИИ-агент программирования |
| Документация | Markdown, UML (PlantUML) | Документация хранится в репозитории рядом с кодом, диаграммы версионируются |

Альтернативы и обоснование каждого решения — в [обзоре](documents/rationale.md) и архитектурных решениях модулей (документы `145`).

## Быстрый старт

> Команды заработают после реализации каркаса (этап до 01.11).

Нужны Docker с Compose, ключ TMDB API и ключ RouterAI.

```bash
cp .env.example .env              # вписать TMDB_API_KEY, LLM_API_KEY и LLM_MODEL
docker compose up --build -d
docker compose run --rm backend python -m scripts.load_catalog
```

Затем откройте http://localhost:8080.

Чтобы посмотреть интерфейс до реализации, откройте интерактивный прототип [`documents/ui/prototype/index.html`](documents/ui/prototype/index.html) в браузере. Фильмы в прототипе вымышленные.
