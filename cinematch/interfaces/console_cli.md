# Консольный интерфейс (typer + rich)

|*CineMatch. Модуль интерфейса* | [оглавление](../README.md)

Текстовая обёртка над единым ядром. Интерфейс строится на `typer` (дерево команд) и `rich` (таблицы, методы ввода, красивый вывод). Всё, что за пределы CLI, делает ядро: подбор, оценки, профиль, удаление данных.

## 1. Структура

```text
cinematch/interfaces/console_cli/
├── __init__.py
├── cli.py          # точка входа: typer.Typer(), меню, парсинг аргументов
├── dialog.py       # FSM-сценарии консольного диалога (ввод, подборка, оценка)
├── db.py           # работа с SQLite через ядро (сессия, профиль, история)
├── metrics.py      # сбор метрик (T_dec, клики, вызовы модели)
└── __main__.py     # python -m cinematch.interfaces.console_cli
```

## 2. Меню

| Номер | Действие | Ввод | Вывод |
|---|---|---|---|
| 1 | Подбор фильма | Настроение, время, компания, город, свободное время | Таблица 3 фильмов с объяснением |
| 2 | История оценок | — | Таблица: фильм, год, оценка, источник, дата |
| 3 | Профиль | — | Веса жанров, актёров, `ratings_count` |
| 4 | Удалить данные | Подтверждение | Результат `DELETE /api/v1/me` |
| 5 | Сохранить оценку | Фильм + оценка 1–10 | Сохранение и профиль пересчитывается |
| 6 | Выход | — | — |

## 3. Правила ввода

- Город берётся первым разом; после этого меню больше города не спрашивает.
- Настроение, время и компания вводятся свободным текстом; бот сам разбирает намерение.
- Фразы вида «без ужасов, на 3 часа, с друзьями» и «посмотрел Тихий дом у моря, на 8» обрабатываются перед запуском подбора.
- Оценка должна быть целым числом от 1 до 10. Иное → запрос повторно.
- Показанные в подборке фильмы — только из локального каталога, никогда выдуманные.

## 4. Вывод подборки (rich.table)

```text
┌  Подбор — Казань, 20:00, с друзьями, без ужасов  ─────┐
│  №  | Фильм                 | 2014 | 1 ч 38 мин | ★ 7,8 | 12+ │
│  1  | Тихий дом у моря      | 2014 | 1 ч 38 мин | ★ 7,8 | 12+ │
│      | драма, комедия                  ↑ путь
│      | спокойная тёплая история для дождливого вечера
│  2  | ...                                      ↑ путь
│  3  | ...                                      ↑ путь
└─────────────────────────────────────────────────────────┘
```

Объяснение выбора выводится рядом с карточкой: одна строка, кратко, без markdown-разметки.

## 5. Метрики

Модуль логирования записывает в `metrics` из ядра:

- `T_dec` — время от первого сообщения до подборки;
- `clicks` — число нажатий/выборов пользователя;
- `llm_calls` — число вызовов модели;
- `tool_calls` — число вызовов инструментов.

Эти данные отдаются через `/api/v1/metrics`.

## 6. Отладка

Безопасный режим: если ядро отвечает `CATALOG_EMPTY` или ошибка сети, консоль выводит понятное сообщение и путь восстановления (выбор города, повтор запрос), не завершая работу.
