## Правила

1. Для общей части и модуля ИИ-агентов нормативным является `cinematch_specs_agents.docx`; при расхождении с базовым ТЗ действует он.
2. Для модуля данных и модуля интерфейса нормативным остаётся базовое ТЗ до выпуска их собственных ТЗ. Границы, которые они должны принять, — приложение Е документа `cinematch_specs_agents.docx`.
3. Общие разделы (состав, архитектура, контракты, конфигурация, безопасность, документация, стадии, приёмка) изменяются только по согласованию всех трёх исполнителей.
4. Исходники ТЗ — в Markdown рядом с DOCX: `cinematch_specs_agents.md`.
