# CineMatch — Vision модуля данных

> Подробная документация модуля — [`documents/data/`](../../documents/data/README.md).

## 1. Общее описание

Модуль данных — единственная часть системы, которая работает с базой данных и внешними источниками данных. Остальные модули не выполняют SQL-запросов и не обращаются к TMDB или Open-Meteo, а вызывают функции модуля.

| Компонент | Роль |
|---|---|
| База данных | SQLite в одном файле: каталог фильмов, пользователи, оценки, выборы, сессии |
| Загрузка каталога | Скрипт, который загружает фильмы из TMDB на русском языке |
| Функции-инструменты | Поиск фильмов, профиль предпочтений, история оценок, погода — для агента |
| Служебные функции | Сессии, настройки, выбор, история, удаление данных — для оркестратора и API |

## 2. Ключевые возможности

1. Локальный каталог из TMDB: жанры, рейтинг, длительность, актёры, постер, возрастная маркировка.
2. Поиск кандидатов по критериям агента с исключением показанных и уже оценённых фильмов.
3. Профиль предпочтений, рассчитываемый из оценок при каждом запросе.
4. Погода по городу пользователя через Open-Meteo, с кэшем.
5. Полное удаление данных пользователя одной транзакцией.
6. Безопасная повторная загрузка каталога и продолжение прерванной.

## 3. Требования

**Функциональные:** загрузка каталога из TMDB с обработкой ошибок и ограничением частоты; `find_movies` по жанрам, годам, рейтингу, длительности с порогом числа голосов; хранение оценок 1–10, выборов, сессий, настроек; история оценок для экрана интерфейса; удаление данных пользователя.

**Нефункциональные:** поиск фильмов — до 50 мс на каталоге до 100 000 фильмов; одновременная работа приложения и загрузки каталога; проверка каждого параметра, пришедшего от модели; внешние ключи и транзакции; изменения схемы только через миграции.

## 4. Взаимодействие

- **С модулем агентов:** инструменты для моделей и служебные функции для оркестратора.
- **С интерфейсом (API):** история оценок, настройки, удаление данных.
- **С внешними системами:** TMDB API (ключ), Open-Meteo (без ключа).

## 5. Процессы

Загрузка каталога, поиск кандидатов, удаление данных — диаграммы в [146 Logic Scheme](../../documents/data/146.logic-scheme.md) и [155 Sequence-диаграммы](../../documents/data/155.sequence-diagrams.md).

## Будущий функционал

Таблицы напоминаний и подписок; проверка новинок и подборка новинок по вкусу; сериалы; статистика для администратора; переход на PostgreSQL при развёртывании для многих пользователей.
