Фикстура каталога — `tests/fixtures/seed_movies.json` (23 фильма, ADR-042), включая фильм с 42 голосами, фильм без длительности и фильм с инструкцией в `overview`. Она не входит в поставку и используется только тестами. Подмена LLM — тестовый двойник, возвращающий заранее заданные `AgentOutput`; реальные вызовы RouterAI в unit-тестах запрещены.

Правило: сценарий считается пройденным, только если проверен весь набор шагов и зафиксирован результат. «Код написан» — не результат.
