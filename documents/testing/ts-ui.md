# TS-UI — сценарии модуля интерфейса

Сценарии выполняются в браузере на поднятом `docker compose`; для ошибок — с заглушкой API.

| ID | Шаги | Ожидаемый результат |
|---|---|---|
| TS-UI-01 | Открыть страницу; принять согласие; назвать город; отправить запрос; дождаться подборки; раскрыть трассу | Первое `progress` ≤ 1 с; три карточки; постеры/заглушки; трасса с шагами; ввод разблокирован |
| TS-UI-02 | Выбрать карточку мышью и клавиатурой; отправить новый запрос | Сообщение «Выбираю «…»»; выбранная карточка отмечена; остальные неактивны; повторная отправка не дублируется |
| TS-UI-03 | Ошибка LLM; таймаут; пустой каталог; второй запрос во время первого | Текст из `contracts §6`; ввод доступен; `409` для второго; `503` при пустом каталоге |
| TS-UI-04 | Открыть историю без оценок и с оценками | Пустое состояние; список с постером, годом, оценкой, источником, датой; новые сверху |
| TS-UI-05 | Сменить город; удалить данные; отменить удаление | Новый город сохранён; удаление с подтверждением; отмена сохраняет данные |
| TS-UI-06 | Ширина 360 px; тёмная/светлая тема; `prefers-reduced-motion` | Нет горизонтальной прокрутки; контраст; анимации отключены; фокус видим |
| TS-UI-07 | Запуск с нуля; перезапуск; загрузка каталога | `docker compose up` открывает страницу; данные сохраняются; `/health` отвечает |

## Критерии приёмки

- TS-UI-01…05, 07 — все шаги пройдены.
- TS-UI-06 — проверено в Chrome/Firefox/Safari последних версий.
- Скриншоты и записи ошибок прикладываются к отчёту.
