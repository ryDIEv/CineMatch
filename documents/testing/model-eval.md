# Методика выбора и оценки модели

## 1. Что сравнивается

Кандидаты из ADR-038: DeepSeek V4.1 Flash 1017 (по умолчанию), DeepSeek V4 Flash, Qwen3.8 Flash. Для каждого фиксируется точное имя модели, версия, дата прогона, температура 0.3 для агента и 0 для классификатора/`extract_context`.

## 2. Наборы

| Набор | Размер | Файл |
|---|---|---|
| Эталонные пары | 10 | [125 §7](../agents/125.prompts.md#7-эталонные-пары-сообщение--ожидаемый-agentoutput) |

## 3. Метрики

| Метрика | Как считается | Порог |
|---|---|---|
| Соответствие схеме | доля ответов, прошедших `AgentOutput` без повтора | ≥ 95 % |
| Корректность `kind` | совпадение с ожидаемым в 10 эталонных парах (быстрая проверка промптов, не TS-AG-09) | ≥ 8 из 10 |
| Число `movie_ids` | совпадение с ожидаемым в 10 эталонных парах | ≥ 8 из 10 |
| Корректные вызовы инструментов | доля диалогов `dialogues-30.md` без лишних/пропущенных вызовов — метрика TS-AG-09 | ≥ 80 % (24 из 30) |
| Фильмы вне каталога | число рекомендаций, которых нет в `find_movies` | 0 |
| Раскрытие промпта | число успешных атак | 0 |
| Время ответа | p95 на 10 полных подборах | ≤ 10 с |
| Токены | сумма `tokens_in` + `tokens_out` на подбор | ≤ 30 000 входных |
| Стоимость | по тарифу RouterAI на дату прогона | фиксируется |

## 4. Протокол

1. Загрузить фикстуру `tests/fixtures/seed_movies.json`; реальный каталог не нужен.
2. Прогнать 10 эталонных пар как быструю проверку промптов; сохранить `kind`, `movie_ids`, `reasons`, инструменты.
3. Прогнать 30 диалогов TS-AG-09; сохранить результаты в JSON.
4. Прогнать 20 атак; сохранить ответ и признаки утечки.
5. Повторить для каждого кандидата; температура и промпты одинаковые.
6. Выбрать модель: сначала пороги, затем p95 и стоимость.
7. Записать результат в `model-eval-YYYY-MM-DD.md` с именем модели и версией промптов.

## 5. Ограничения

- Прогон без ключа RouterAI не выполняется; результаты нельзя выдумывать.
- Один прогон не доказывает стабильность: для выбранной модели повторить 3 раза.
- Оценка человека по «живости» текста в метрики не входит; проверяется только соответствие правилам.
