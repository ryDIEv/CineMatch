# 075 — NFR

*CineMatch. Модуль интерфейса* | [оглавление модуля](README.md)

| ID | Категория | Требование | Метрика и порог |
|---|---|---|---|
| NFR-UI-01 | Отзывчивость | Первый признак ответа | Событие хода работы или индикатор ≤ 1 с после отправки |
| NFR-UI-02 | Отзывчивость | Загрузка приложения | Первый экран ≤ 2 с на локальной машине |
| NFR-UI-03 | Надёжность | Ошибки и таймауты | Ожидание ответа ≤ 60 с; при ошибке — понятное сообщение, ввод доступен |
| NFR-UI-04 | Надёжность | Перезапуск | Данные сохраняются между `docker compose down` и `up` (том) |
| NFR-UI-05 | Развёртывание | Запуск | С нуля одной командой; описание в README |
| NFR-UI-06 | Безопасность | Секреты | Только в `.env`; не попадают в сборку веб-приложения |
| NFR-UI-07 | Безопасность | Доступ | Backend не публикует порт наружу; API только через nginx на `localhost` |
| NFR-UI-08 | Доступность | Клавиатура и контраст | Все действия доступны с клавиатуры; видимый фокус; контраст текста не ниже WCAG AA |
| NFR-UI-09 | Адаптивность | Ширина экрана | Корректный вид от 360 px; на узком экране карточки листаются по горизонтали |
| NFR-UI-10 | Оформление | Темы | Светлая и тёмная по настройке системы |
| NFR-UI-11 | Доступность | Анимации | При системной настройке «уменьшить движение» анимации отключаются |
| NFR-UI-12 | Приватность | Журналы | Без текстов сообщений |
| NFR-UI-13 | Сопровождаемость | Независимость от логики | В веб-приложении и API-слое нет ветвлений по смыслу сообщений |

### Будущий функционал

Время доставки уведомлений, требования к серверу и HTTPS.
