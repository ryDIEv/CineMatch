# 115 — Live-прототип

*CineMatch. Модуль интерфейса* | [оглавление модуля](README.md)

Интерактивный прототип: [`prototype/index.html`](prototype/index.html) — один файл, открывается в браузере (GitHub показывает HTML как исходный текст: файл нужно скачать или включить GitHub Pages).

| Сценарий в прототипе | Варианты использования |
|---|---|
| Первый визит | UC-1, UC-2 |
| Подбор и выбор карточкой | UC-3, UC-4 |
| Оценка при следующем визите | UC-5 |
| Отметка просмотренного | UC-6 |
| Запрос не по теме | UC-8 |
| Экран «История и оценки» | UC-10 |

Реплики пользователя подготовлены заранее: их можно отправить или изменить. Фильмы в прототипе вымышленные, постеры заменены цветными заглушками.

### Будущий функционал

Прототипы экрана подборки новинок и Telegram-бота.
