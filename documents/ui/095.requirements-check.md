# 095 — Traceability Matrix

*CineMatch. Модуль интерфейса* | [оглавление модуля](README.md)

## 1. Функциональные требования

| ID | Требование |
|---|---|
| FR-UI-01 | Отправка сообщения и потоковый ответ (события хода работы и итоговый ответ) |
| FR-UI-02 | Отображение всех типов ответа агента: `consent`, `question`, `recommendations`, `feedback_question`, `confirmation`, `message`, `error` |
| FR-UI-03 | Карточки-билеты: постер, название, год, длительность, возрастная маркировка, рейтинг, жанры, объяснение |
| FR-UI-04 | Выбор фильма нажатием на карточку |
| FR-UI-05 | Раскрываемая трасса решений |
| FR-UI-06 | Экран «История и оценки» |
| FR-UI-07 | Экран «Мои данные»: город, удаление данных с подтверждением |
| FR-UI-08 | Проверка ввода: пустое сообщение, более 1000 символов |
| FR-UI-09 | Запуск через Docker Compose; загрузка каталога командой |
| FR-UI-10 | Определение текущего пользователя в одном месте API-слоя |
