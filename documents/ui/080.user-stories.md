# 080 — User Stories

*CineMatch. Модуль интерфейса* | [оглавление модуля](README.md)

Истории, где интерфейс передаёт сообщения агенту, — в [080 модуля агентов](../agents/080.user-stories.md). Истории модуля интерфейса:

**US-17.** Как пользователь, я хочу видеть, что агент работает, чтобы не отправлять сообщение повторно. *(UC-3)*
- Given сообщение отправлено, When агент готовит ответ, Then в течение 1 с появляется строка хода работы («Ищу фильмы…»), поле ввода заблокировано до ответа.

**US-18.** Как пользователь, я хочу выбрать фильм нажатием на карточку, чтобы не печатать название. *(UC-4)*
- Given показана подборка, When пользователь нажимает на вторую карточку, Then в ленте появляется «Выбираю «…»», карточка отмечена, остальные неактивны, агент подтверждает выбор.

**US-19.** Как пользователь, я хочу видеть историю оценок, чтобы вспомнить, что смотрел. *(UC-10)*
- Given есть оценки, When пользователь открывает «История и оценки», Then видит фильмы с постером, оценкой и датой, новые сверху.
- Given оценок нет, When экран открыт, Then показывается приглашение подобрать фильм.

**US-20.** Как пользователь, я хочу управлять своими данными в одном месте. *(UC-11, UC-7)*
- Given открыт «Мои данные», When пользователь меняет город, Then следующая подборка учитывает погоду в новом городе.
- Given открыт «Мои данные», When пользователь нажимает «Удалить мои данные» и подтверждает, Then данные удалены и приложение начинается с согласия.

**US-21.** Как пользователь, я хочу удобно пользоваться приложением на любом экране и с клавиатуры. *(все)*
- Given ширина экрана 360 px, When показана подборка, Then карточки листаются по горизонтали, текст не обрезается.
- Given пользователь работает с клавиатуры, When он переходит по элементам, Then фокус виден, карточку можно выбрать клавишей Enter.

**US-22.** Как сопровождающий, я хочу запустить приложение одной командой, чтобы показать его на любом компьютере. *(UC-12)*
- Given установлен Docker и заполнен `.env`, When выполняется `docker compose up --build`, Then приложение доступно на `localhost:8080`.
