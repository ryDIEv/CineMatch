# 145 — ADR

*CineMatch. Модуль интерфейса* | [оглавление модуля](README.md)

Нумерация сквозная по проекту; полный порядок — в [145 модуля агентов](../agents/145.architecture-decisions.md).

**ADR-019. Веб-приложение на React, TypeScript и Vite.** *Принято.* Контекст: требуется профессиональный и красивый интерфейс, проект для портфолио. Решение: React + TypeScript, сборка Vite, своя дизайн-система ([110](110.ui-ux.md)). Последствия: (+) стандарт индустрии, типизация, хорошая поддержка ИИ-агентами программирования; (−) отдельная сборка и второй язык в проекте.

**ADR-020. API на FastAPI с потоковыми ответами SSE.** *Принято.* Контекст: ответ агента занимает несколько секунд. Решение: FastAPI; `POST /messages` отдаёт поток событий хода работы и итоговый ответ; `handle_user_turn` выполняется в рабочем потоке. Последствия: (+) пользователь видит работу агента, документация API генерируется автоматически; (−) обработка обрывов потока в клиенте.

**ADR-021. Docker Compose, запуск на localhost.** *Принято.* Контекст: проверяющий и команда должны запускать проект одинаково. Решение: контейнеры frontend (nginx со сборкой) и backend (Python), том для базы. Последствия: (+) запуск одной командой на любой ОС; (−) нужен установленный Docker.

**ADR-022. Один пользователь с расчётом на многих.** *Принято.* Контекст: MVP локальный, но архитектура должна масштабироваться. Решение: `user_id` определяется в одном месте (`CurrentUser`), в MVP — `web:local`; все данные привязаны к `user_id`. Последствия: (+) вход добавляется заменой одной зависимости; (−) в MVP нет разделения профилей.

**ADR-023. Постеры загружаются браузером с image.tmdb.org.** *Принято.* Последствия: (+) не нужно хранить изображения; (−) без интернета постеры не показываются — карточка отображается с цветной заглушкой.

**ADR-024. Интерфейс без логики подбора.** *Принято.* Решение: веб-приложение и API-слой передают сообщения модулю ИИ-агентов и отображают ответы; нажатие на карточку — тоже сообщение. Последствия: (+) Telegram-бот в будущем подключается к тому же контракту; (−) все особенности поведения реализуются в модуле ИИ-агентов.

**ADR-028. Python 3.14, менеджер пакетов uv.** *Принято.* Контекст: версия 3.12 получает только исправления безопасности. Решение: Python 3.14 в контейнере backend; зависимости и lock-файл — через uv; если зависимость не поддерживает 3.14, используется 3.13. Последствия: (+) поддержка версии до 2030 года, воспроизводимая установка; (−) часть библиотек может отставать по поддержке новой версии.
