# 030 — Actors

*CineMatch. Модуль интерфейса* | [оглавление модуля](README.md)

Системные акторы — в [030 модуля агентов](../agents/030.actors.md). Для модуля интерфейса:

| Актор | Тип | Цели |
|---|---|---|
| Пользователь | Человек | Общаться с агентами, смотреть историю, управлять данными |
| Сопровождающий | Человек (участник команды) | Запустить приложение одной командой |
| Модуль ИИ-агентов | Внутренняя система | Получить сообщение, вернуть ответ |
| Модуль данных | Внутренняя система | Отдать историю, сохранить настройки, удалить данные |

### Будущий функционал

Пользователь Telegram; администратор (экран статистики).
