# 140 — Event Schema

*CineMatch. Модуль интерфейса* | [оглавление модуля](README.md)

| Событие | Поля `data` |
|---|---|
| `progress` | `step` (`classify`, `tool`, `check`), `text` (string) — готовая фраза |
| `response` | `AgentResponse` ([130 модуля агентов](../agents/130.api-contracts.md)) |
| `error` | `code` (string), `message` (string) |

`progress` не входит ни в `AgentResponse`, ни в журнал: событие живёт только внутри хода работы ([contracts §3](../overall/contracts.md#3-сообщения-о-ходе-работы)).

`UserDataDeleted` издаёт модуль данных при `DELETE /api/v1/me`; схема — [140 агентов](../agents/140.event-schema.md), интерфейс полей не добавляет. Журнал — общие поля из [140 модуля агентов](../agents/140.event-schema.md); `MessageSent.payload`: `length` (int), `via` (`text`, `card`) — без текста сообщения.
