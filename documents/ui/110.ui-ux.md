# 110 — UI/UX

*CineMatch. Модуль интерфейса* | [оглавление модуля](README.md)

**Концепция.** Вечерний кинозал: сумеречный фиолетовый фон, тёплый «свет проектора» для акцентов, карточки фильмов в виде билетов с отрывной линией. Главный элемент интерфейса — три билета подборки; всё остальное спокойное и сдержанное.

| Токен | Тёмная тема | Светлая тема | Назначение |
|---|---|---|---|
| Фон «сумерки» | `#211E33` | `#F1EEF7` | Фон страницы |
| Поверхность «зал» | `#2B2742` | `#FFFFFF` | Панели, карточки |
| Текст | `#EFEBF8` | `#231F37` | Основной текст |
| Приглушённый | `#AAA3C6` | `#6D6688` | Подписи, ход работы |
| Акцент «проектор» | `#F2C46D` | `#A8740F` | Кнопка отправки, выбранная карточка, фокус |

Шрифты: Prata — названия фильмов и заголовки экранов; Golos Text — интерфейс и текст. Оба поддерживают кириллицу.

**Принципы**

| Принцип | Применение |
|---|---|
| Диалог вместо меню | В чате нет кнопок-вариантов; единственные кнопки — «Принимаю» / «Не сейчас» в согласии и «Отправить» |
| Карточка — подсказка | Нажатие на карточку формирует обычное сообщение, решение принимает агент |
| Обратная связь | Ход работы агентов виден сразу; действия с данными подтверждаются агентом |
| Прозрачность | «Как агент выбирал» — свёрнуто по умолчанию, раскрывается одним нажатием |
| Доступность | Фокус видим, всё доступно с клавиатуры, анимации отключаются по настройке системы |

**Экраны**

| Экран | Состав | Состояния |
|---|---|---|
| Чат | Боковая панель (Подбор, История и оценки, Мои данные), строка с городом и погодой, лента, поле ввода | Загрузка, ход работы, ошибка, сервер недоступен |
| История и оценки | Список: постер, название, год, оценка, источник оценки, дата | Пусто — приглашение подобрать фильм |
| Мои данные | Город (поиск с вариантами), что хранится, «Удалить мои данные» с подтверждением | Сохранено, ошибка поиска города |

**Карточка-билет**

```
┌──────────────────────────┐
│ [постер]            12+  │
│                          │
│ Тихий дом у моря         │
├ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─┤
│ 2014  1 ч 38 мин  ★ 7,8  │
│ драма, комедия           │
│ Спокойная тёплая история │
│ для дождливого вечера.   │
│ Выбрать этот фильм       │
└──────────────────────────┘
```

**Навигация.** Боковая панель; на узком экране — верхняя полоса. История открывается панелью поверх чата, чат не теряется. Привязка к сценариям: чат — UC-1…UC-8, история — UC-10, мои данные — UC-7, UC-11.

### Будущий функционал

Экран подборки новинок; переключатель профилей; экран статистики.
