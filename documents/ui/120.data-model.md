# 120 — Data Model

*CineMatch. Модуль интерфейса* | [оглавление модуля](README.md)

Модуль не хранит данных пользователей: состояние диалога — у модуля агентов, остальное — у модуля данных.

| Данные | Где | Время жизни |
|---|---|---|
| Лента сообщений текущего визита | Память веб-приложения | До перезагрузки страницы (история оценок — на сервере) |
| Предпочтение темы | Настройка системы | — |

**Конфигурация (`.env`).** Единственный источник переменных и значений по умолчанию — [overall/config.md](../overall/config.md). Модуль интерфейса читает только `CINEMATCH_USER_ID` и `AGENT_TIMEOUT_S`; остальные переменные принадлежат модулям агентов и данных. Дублировать таблицу здесь нельзя: при расхождении прав `../overall/config.md`.

### Будущий функционал

Таблица пользователей с данными входа (в модуле данных).
