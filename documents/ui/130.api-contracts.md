# 130 — API Contracts

*CineMatch. Модуль интерфейса* | [оглавление модуля](README.md)

REST API backend, базовый путь `/api/v1`, формат JSON. Версия REST API — `0.1.0`, версия `AgentResponse` — `0.2.0` ([130 модуля агентов](../agents/130.api-contracts.md)) (semver; несовместимое изменение — новая версия пути). Схема OpenAPI генерируется FastAPI автоматически: `/api/docs`.

| Метод и путь | Назначение | Ответ |
|---|---|---|
| `GET /api/v1/health` | Проверка работы | `{"status": "ok", "catalog_size": 8421}` |
| `GET /api/v1/session` | Состояние при открытии | `{"consent": true, "city": "Москва", "has_pending_feedback": true}` |
| `POST /api/v1/messages` | Сообщение агенту, ответ потоком SSE | события `progress`, `response`, `error` |
| `GET /api/v1/history?limit=50` | История оценок и выборов | `{"items": [...]}` |
| `GET /api/v1/cities?query=каз` | Варианты города | `{"items": [{"name": "Казань", "region": "Татарстан", "country": "Россия", "latitude": 55.79, "longitude": 49.12}]}` |
| `PUT /api/v1/settings` | Сохранить город | `{"city": "Казань"}` |
| `DELETE /api/v1/me` | Удалить данные пользователя | `{"deleted_counts": {"user_ratings": 12, "user_choices": 3}}` |

**POST /api/v1/messages**

Запрос:

```json
{"text": "Выбираю «Двое и собака»", "movie_id": 205}
```

Ответ — поток `text/event-stream`:

```
event: progress
data: {"text": "Определяю, что вы выбрали"}

event: response
data: {"contract_version": "0.2.0", "type": "confirmation", "text": "Хороший выбор на вечер…", "movies": [], "trace": [], "stage": "dialog"}
```

Ошибка в потоке:

```
event: error
data: {"code": "LLM_UNAVAILABLE", "message": "Не удалось получить ответ модели. Попробуйте ещё раз."}
```

Формат `AgentResponse` — [130 модуля агентов](../agents/130.api-contracts.md).

**Ошибки HTTP**

| Код | Когда | Тело |
|---|---|---|
| 400 | Пустой текст или более 1000 символов | `{"code": "INVALID_INPUT", "message": "…"}` |
| 404 | Город не найден | `{"code": "CITY_NOT_FOUND", "message": "…"}` |
| 503 | Каталог не загружен | `{"code": "CATALOG_EMPTY", "message": "Загрузите каталог командой …"}` |

### Будущий функционал

Аутентификация (заголовок `Authorization`), эндпоинты подборки новинок и подписок, вебхук Telegram-бота.
