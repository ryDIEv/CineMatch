# 010 — Глоссарий

*CineMatch. Модуль интерфейса* | [оглавление модуля](README.md)

| Термин | English | Определение |
|---|---|---|
| Веб-приложение | Web app | Клиентская часть в браузере: чат, карточки, экраны истории и данных |
| API-слой | API layer | Сервер на FastAPI: REST-эндпоинты и поток событий поверх модулей агентов и данных |
| Поток событий | Server-Sent Events (SSE) | Ответ сервера, передаваемый частями: сначала события хода работы, затем итоговый ответ |
| Событие хода работы | Progress event | Короткое сообщение о текущем шаге агента: «Ищу фильмы…» |
| Карточка-билет | Movie ticket | Карточка фильма в виде билета: постер, название, год, длительность, возрастная маркировка, рейтинг, жанры, объяснение |
| Выбор карточкой | Card pick | Нажатие на карточку; отправляет сообщение «Выбираю «…»», решение принимает агент |
| Трасса решений | Agent trace | Раскрываемый блок «Как агент выбирал» под подборкой |
| Текущий пользователь | Current user | Идентификатор пользователя, который API-слой передаёт модулям; в MVP — `web:local` |
| Docker Compose | Docker Compose | Описание контейнеров приложения и их запуск одной командой |
| Том | Volume | Хранилище Docker для файла базы, сохраняющееся между перезапусками |
| Обратный прокси | Reverse proxy | nginx в контейнере frontend: отдаёт веб-приложение и перенаправляет `/api` в backend |

### Будущий функционал
