# 135 — Event Catalog

*CineMatch. Модуль интерфейса* | [оглавление модуля](README.md)

Брокер не используется. События интерфейса — события потока SSE и строки журнала.

| Событие | Издатель | Обработчики | Триггер | Критичность |
|---|---|---|---|---|
| `progress` (SSE) | API-слой | Веб-приложение | Шаг агента | средняя |
| `response` (SSE) | API-слой | Веб-приложение | Ответ агента | высокая |
| `error` (SSE) | API-слой | Веб-приложение | Ошибка или таймаут | высокая |
| `MessageSent` | API-слой | Журнал | Каждое сообщение | низкая |
| `UserDataDeleted` | Модуль данных (`delete_user_data`) | Журнал | `DELETE /me` из API-слоя | высокая |
