# 070 — RBAC

*CineMatch. Модуль интерфейса* | [оглавление модуля](README.md)

В MVP один локальный пользователь: API-слой определяет `user_id = web:local` для каждого запроса через зависимость `CurrentUser`. Все эндпоинты и вызовы модулей получают `user_id` только из неё — это позволяет добавить вход без изменения остального кода.

| Действие | Пользователь |
|---|---|
| Чат с агентами | ✅ |
| История и оценки | ✅ (только свои) |
| Изменение города | ✅ |
| Удаление своих данных | ✅ (с подтверждением) |

API доступен только на `localhost`; порт backend наружу не публикуется, запросы идут через nginx.

### Будущий функционал

Вход (например, по ссылке из Telegram или паролю), роль администратора с экраном статистики, ограничение частоты запросов.
