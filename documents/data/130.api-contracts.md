# 130 — API Contracts

*CineMatch. Модуль данных* | [оглавление модуля](README.md)

Модуль предоставляет функции Python в процессе backend; REST API у модуля нет. Ошибки проверки параметров возвращаются как `ToolError(code, message)`, чтобы модель могла исправить вызов. Версия контракта — `0.1.0`.

**Инструменты** (`user_id` и исключения подставляет код модуля агентов)

| Функция | Результат | Ошибки |
|---|---|---|
| `get_user_ratings(user_id, limit=20)` | `[{movie_id, title, year, genres, rating, mood_match, rated_at}]` | `INVALID_PARAM` |
| `get_weather(user_id)` | `{city, condition, temp_c, is_day}` или `None` | — |
| `get_user_profile(user_id)` | `{genre_weights: {жанр: −1…1}, actor_weights: {…}, ratings_count}` | — |
| `find_movies(user_id, genres, year_from, year_to, min_rating, max_runtime, exclude_ids, limit=15)` | `[MovieCard]` по убыванию рейтинга | `INVALID_PARAM`, `UNKNOWN_GENRE` |
| `get_movie_with_credits(movie_id)` | `MovieCard` + `actors`, `overview` | `NOT_FOUND` |
| `search_movie(title, year=None)` | до 5 совпадений `{movie_id, title, year}` | `INVALID_PARAM` |
| `save_rating(user_id, movie_id, rating, mood_match=None, source)` | `{saved: true, closed_choice_id}` | `INVALID_PARAM`, `NOT_FOUND` |

`MovieCard`: `{movie_id, tmdb_id, title, year, runtime, rating, vote_count, age_rating, genres, poster_url}`.

**Служебные функции**

| Функция | Вызывает | Назначение |
|---|---|---|
| `get_user(user_id)` | оркестратор, API-слой | Настройки пользователя или `None` |
| `save_consent(user_id, source)` | оркестратор | Создать пользователя с `consent_at` |
| `resolve_city(name)` | оркестратор, API-слой | До 5 вариантов `{name, region, country, latitude, longitude}` |
| `save_user_settings(user_id, city, latitude, longitude)` | оркестратор, API-слой | Сохранить город |
| `get_session_state` / `save_session_state` / `clear_session_state` | оркестратор | Состояние диалога; сохранение продлевает срок на 24 ч |
| `save_choice(user_id, movie_id)` | оркестратор | Новый выбор; прежний ожидающий → `dismissed` |
| `get_pending_feedback(user_id)` | оркестратор, API-слой | Ожидающий выбор с карточкой фильма или `None` |
| `close_choice(choice_id, status)` | оркестратор | `dismissed` («не смотрел») |
| `get_history(user_id, limit=50)` | API-слой | Оценки и выборы с карточками фильмов, по убыванию даты |
| `delete_user_data(user_id)` | оркестратор, API-слой | Удаление; `{deleted_counts}` |
| `purge_expired()` | запуск backend | Удаление просроченных сессий |
| `ingest_movies(pages, from_year, min_votes, resume)` | скрипт загрузки | UC-9 |

**Запросы к внешним системам**

| Система | Запрос | Параметры |
|---|---|---|
| TMDB | `GET /3/genre/movie/list` | `language=ru-RU` |
| TMDB | `GET /3/discover/movie` | `language=ru-RU`, `sort_by=popularity.desc`, `vote_count.gte`, `primary_release_date.gte`, `page` |
| TMDB | `GET /3/movie/{id}` | `language=ru-RU`, `append_to_response=credits,release_dates` |
| Open-Meteo | `GET geocoding-api.open-meteo.com/v1/search` | `name`, `count=5`, `language=ru` |
| Open-Meteo | `GET api.open-meteo.com/v1/forecast` | `latitude`, `longitude`, `current=temperature_2m,weather_code,is_day` |

Пример ошибки инструмента: `{"error": {"code": "UNKNOWN_GENRE", "message": "Жанр «киберпанк» отсутствует. Допустимые: боевик, комедия, драма, …"}}`.

### Будущий функционал

`search_series`, `create_reminder`, `subscribe`, `check_releases`, `get_new_releases_for(user_id)`.
