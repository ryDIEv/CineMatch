# 075 — NFR

*CineMatch. Модуль данных* | [оглавление модуля](README.md)

| ID | Категория | Требование | Метрика и порог |
|---|---|---|---|
| NFR-DB-01 | Производительность | `find_movies` | ≤ 50 мс на каталоге до 100 000 фильмов |
| NFR-DB-02 | Производительность | Остальные функции чтения | ≤ 20 мс |
| NFR-DB-03 | Производительность | Запись при загрузке | ≥ 500 записей/с в одной транзакции |
| NFR-DB-04 | Производительность | `get_weather` | Таймаут 3 с; повтор по тому же городу в течение 30 мин — из кэша |
| NFR-DB-05 | Внешние ограничения | Запросы к TMDB | ≤ 40 запросов/с, интервал ≥ 25 мс; при 429 — пауза с увеличением |
| NFR-DB-06 | Надёжность | Параллельный доступ | Приложение и загрузка каталога работают одновременно без ошибок блокировки (WAL, `busy_timeout` 5 с) |
| NFR-DB-07 | Надёжность | Целостность | Внешние ключи включены для каждого подключения; запись только в транзакциях |
| NFR-DB-08 | Надёжность | Возобновление загрузки | Прерванная загрузка продолжается с последней сохранённой страницы |
| NFR-DB-09 | Приватность | Удаление данных | Все записи пользователя удаляются одной транзакцией |
| NFR-DB-10 | Приватность | Журналы | Без городов, оценок и текстов — только `user_id` и тип операции |
| NFR-DB-11 | Безопасность | Параметры от модели | Каждый параметр проверяется по типу и диапазону; SQL только с подстановкой параметров |
| NFR-DB-12 | Объём | Каталог MVP | 5 000–10 000 популярных фильмов, порог голосов ≥ 100 (уточняется) |
| NFR-DB-13 | Лицензирование | Атрибуция TMDB | Источник и уведомление TMDB указаны в интерфейсе и README |
| NFR-DB-14 | Сопровождаемость | Изменения схемы | Только через миграции; версия в `PRAGMA user_version` |

### Будущий функционал

Переход на PostgreSQL при развёртывании для многих пользователей; резервное копирование на сервере.
