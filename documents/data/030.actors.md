# 030 — Actors

*CineMatch. Модуль данных* | [оглавление модуля](README.md)

Системные акторы — в [030 модуля агентов](../agents/030.actors.md). Для модуля данных:

| Актор | Тип | Цели |
|---|---|---|
| Модуль ИИ-агентов | Внутренняя система | Найти фильмы, прочитать и сохранить данные пользователя |
| API-слой | Внутренняя система | Получить историю и настройки, удалить данные |
| Сопровождающий | Человек (участник команды) | Загрузить и обновить каталог |
| TMDB API | Внешняя система | Отдать метаданные фильмов |
| Open-Meteo | Внешняя система | Отдать координаты города и погоду |

### Будущий функционал

Планировщик (в Telegram-боте) — получать напоминания и запускать проверку новинок.
