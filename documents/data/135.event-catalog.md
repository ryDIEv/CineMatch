# 135 — Event Catalog

*CineMatch. Модуль данных* | [оглавление модуля](README.md)

Брокер сообщений не используется: событие — факт изменения данных, который пишется в журнал строкой JSON и (для загрузки) попадает в отчёт. Общая форма записи — [140 модуля агентов](../agents/140.event-schema.md); схемы `payload` — [140](140.event-schema.md).

| Событие | Издатель | Обработчики | Триггер | Критичность |
|---|---|---|---|---|
| `CatalogLoadStarted` | Скрипт загрузки | Журнал | Старт `ingest_movies` | низкая |
| `MoviesUpserted` | Репозиторий каталога | Журнал | Коммит страницы (20 фильмов) | низкая |
| `CatalogLoadFinished` | Скрипт загрузки | Сопровождающий (отчёт), журнал | Окончание загрузки | средняя |
| `ConsentAccepted` | Оркестратор | Журнал | `set_consent`, после `save_consent` | высокая |
| `CitySaved` | Оркестратор | Журнал | `save_user_settings` | низкая |
| `MovieChosen` | Модуль данных | Журнал | `save_choice` | средняя |
| `RatingSaved` | Модуль данных | Профиль (пересчёт при следующем чтении), журнал | `save_rating` | высокая |
| `SessionExpired` | Очистка | Журнал | `purge_expired` (24 ч без активности) | низкая |
| `UserDataDeleted` | Модуль данных | Журнал | `delete_user_data` | высокая |

Правила:

1. Событие не является сообщением между модулями: получателей, очередей и подписок нет, «обработчик» — строка журнала или пересчёт при следующем чтении.
2. `payload` не содержит текстов города, оценок и сообщений: только идентификаторы, числа и коды ([NFR-DB-10](075.nfr.md)).
3. События загрузки пишутся с `load_id`; пользовательские — с `user_id`. У `SessionExpired` `user_id = null`: очистка пакетная.
4. Имена событий общие с модулем агентов и не переименовываются в модуле данных: `ConsentAccepted`, `CitySaved`, `MovieChosen`, `RatingSaved`, `UserDataDeleted` определены в [140 агентов](../agents/140.event-schema.md).

### Будущий функционал

`ReleaseDetected` — основа подборки новинок и уведомлений.
