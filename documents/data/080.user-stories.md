# 080 — User Stories

*CineMatch. Модуль данных* | [оглавление модуля](README.md)

Истории, в которых участвует модуль, — в [080 модуля агентов](../agents/080.user-stories.md). Истории модуля данных:

**US-13.** Как сопровождающий, я хочу загрузить каталог одной командой, чтобы подготовить приложение к работе. *(UC-9)*
- Given ключ TMDB задан, When запускается загрузка на 50 страниц, Then в базе до 1 000 фильмов с жанрами, актёрами, постерами и возрастной маркировкой, в конце выводится отчёт.
- Given ключ неверный, When запускается загрузка, Then она останавливается с понятным сообщением.

**US-14.** Как пользователь, я хочу не получать в подборке фильмы, которые уже оценил. *(UC-3)*
- Given фильм оценён, When агент вызывает `find_movies`, Then фильм не возвращается.

**US-15.** Как сопровождающий, я хочу безопасно перезапускать загрузку, чтобы обновлять каталог и продолжать прерванную. *(UC-9)*
- Given загрузка прервана на странице 20, When она запущена снова, Then продолжается со страницы 21.
- Given фильм уже в каталоге, When он загружается повторно, Then запись обновляется без дубликата.

**US-16.** Как пользователь, я хочу, чтобы в подборку не попадали малоизвестные фильмы со случайно высоким рейтингом. *(UC-3)*
- Given фильм с рейтингом 9,5 и 12 голосами, When выполняется `find_movies`, Then фильм не возвращается.
