# 110 — UI/UX

*CineMatch. Модуль данных* | [оглавление модуля](README.md)

Пользовательского интерфейса у модуля нет: экраны — в [модуле интерфейса](../ui/110.ui-ux.md). Интерфейс модуля — командная строка скрипта загрузки:

```
docker compose run --rm backend python -m scripts.load_catalog [--pages N] [--from-year Y] [--min-votes V] [--resume]
```

| Параметр | По умолчанию | Назначение |
|---|---|---|
| `--pages N` | 50 | Число страниц `discover/movie` (20 фильмов на странице) |
| `--from-year Y` | 1970 | Нижняя граница года выхода |
| `--min-votes V` | 100 | Минимальное число голосов |
| `--resume` | выкл. | Продолжить последнюю незавершённую загрузку |

Строка прогресса (страница N из M, загружено, пропущено), итоговый отчёт, понятное сообщение и ненулевой код завершения при ошибке.

### Будущий функционал

Параметр `--series` для загрузки сериалов.
