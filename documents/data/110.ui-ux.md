# 110 — UI/UX

*CineMatch. Модуль данных* | [оглавление модуля](README.md)

Пользовательского интерфейса у модуля нет: экраны — в [модуле интерфейса](../ui/110.ui-ux.md). Интерфейс модуля — командная строка скрипта загрузки:

```
docker compose run --rm backend python -m scripts.load_catalog [--pages N] [--from-year Y] [--min-votes V] [--resume]
```

| Параметр | По умолчанию | Границы | Назначение |
|---|---|---|---|
| `--pages N` | 500 | 1…500 | Число страниц `discover/movie` (20 фильмов на странице); 500 — предел TMDB и объём каталога 10 000 фильмов ([ADR-041](145.architecture-decisions.md#adr-041)) |
| `--from-year Y` | 1970 | 1900…2030 | Нижняя граница года выхода |
| `--min-votes V` | 100 | 0…100 000 | Минимальное число голосов (порог NFR-DB-12) |
| `--resume` | выкл. | — | Продолжить последнюю незавершённую загрузку |

## 1. Вывод

Строка прогресса обновляется на каждой странице, в stderr, без переносов:

```
page 137/500  films 2740  skipped 3  elapsed 01:52
```

Итоговый отчёт — в stdout, после завершения:

```
load_id=3 status=completed pages=500 films_upserted=9987 films_skipped=13 duration=6m52s
```

При прерывании или ошибке отчёт тот же, но `status=partial` или `status=failed`, и в stderr — одна строка с причиной.

## 2. Коды завершения

| Код | Когда | Что видит сопровождающий |
|---|---|---|
| 0 | `completed` | отчёт |
| 1 | `partial`: `Ctrl+C` или исчерпаны повторы | отчёт + «Загрузка прервана на странице N. Запустите с --resume.» |
| 2 | нет `TMDB_API_KEY`, ответ 401 | «Ключ TMDB не принят (401). Проверьте TMDB_API_KEY.» |
| 3 | ошибка базы (диск, блокировка, миграции) | «Не удалось записать каталог: <текст ошибки>.» |
| 4 | TMDB недоступен после 5 повторов | «TMDB не отвечает. Повторите позже или запустите с --resume.» |

Тексты — для сопровождающего, не для пользователя приложения: в диалоге эти сообщения не появляются.

## 3. Примеры

```bash
# подготовить каталог целиком
docker compose run --rm backend python -m scripts.load_catalog

# быстрая проверка на пяти страницах (≈100 фильмов)
docker compose run --rm backend python -m scripts.load_catalog --pages 5

# обновить каталог, начиная с фильмов 2000 года, порог 500 голосов
docker compose run --rm backend python -m scripts.load_catalog --from-year 2000 --min-votes 500

# продолжить прерванную загрузку
docker compose run --rm backend python -m scripts.load_catalog --resume
```

### Будущий функционал

Параметр `--series` для загрузки сериалов; вывод прогресса в JSON для внешнего мониторинга.
