# 095 — Traceability Matrix

*CineMatch. Модуль данных* | [оглавление модуля](README.md)

**Функциональные требования**

| ID | Требование |
|---|---|
| FR-DB-01 | Загрузка каталога из TMDB на русском: фильмы, жанры, актёры, постеры, возрастная маркировка |
| FR-DB-02 | Повторная загрузка обновляет записи без дубликатов и продолжает прерванную |
| FR-DB-03 | Обработка ошибок TMDB: 429 — повтор с паузой, 404 — пропуск, 401 — остановка |
| FR-DB-04 | `find_movies` по жанрам, годам, рейтингу, длительности с исключением показанных и оценённых, порогом голосов, сортировкой по рейтингу |
| FR-DB-05 | `get_movie_with_credits`, `search_movie` |
| FR-DB-06 | `get_user_ratings`, `get_user_profile` (пустой профиль при холодном старте) |
| FR-DB-07 | Оценки 1–10 с источником и признаком попадания в настроение; закрытие ожидающего выбора |
| FR-DB-08 | Согласие, город с координатами, `resolve_city` |
| FR-DB-09 | Сессии: чтение, сохранение с продлением, очистка просроченных |
| FR-DB-10 | Выборы и `get_pending_feedback` |
| FR-DB-11 | `get_weather` с кэшем, `None` при недоступности |
| FR-DB-12 | `get_history` для экрана истории |
| FR-DB-13 | `delete_user_data` — каскадное удаление одной транзакцией |

**Тестовые сценарии**

| ID | Проверка |
|---|---|
| TS-DB-01 | Загрузка 5 страниц на пустую базу, отчёт |
| TS-DB-02 | Повторная загрузка — дубликатов нет; прерывание и продолжение |
| TS-DB-03 | Неверный ключ; имитация 429 |
| TS-DB-04 | `find_movies`: фильтры, исключения, порог, сортировка, неверные параметры; время на 10 000 фильмов |
| TS-DB-05 | Профиль: пустой, после 5 оценок, изменение после новой оценки |
| TS-DB-06 | Оценка и выбор: шкала, повторная оценка, закрытие выбора |
| TS-DB-07 | Погода: известный и неоднозначный город, недоступный сервис, кэш |
| TS-DB-08 | Удаление данных: все таблицы пользователя пусты, каталог не затронут |
| TS-DB-09 | Одновременная работа приложения и загрузки |
