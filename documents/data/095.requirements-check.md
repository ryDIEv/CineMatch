## 2. Тестовые сценарии

| ID | Проверка | Набор данных |
|---|---|---|
| TS-DB-01 | Загрузка 5 страниц на пустую базу; отчёт с `load_id`, счётчиками и временем; запись `catalog_loads`; метрики NFR-DB-03, 12, 15, 16 | мок TMDB |
| TS-DB-02 | Повторная загрузка — дубликатов нет, `movies.id` не меняется; прерывание на середине и продолжение с `last_page + 1` | мок TMDB |
| TS-DB-03 | Неверный ключ (401 → `failed`, exit 2); 429 с `Retry-After`; 404 на детали → пропуск; 5xx → повторы, затем `partial` | мок TMDB |
| TS-DB-04 | `find_movies`: каждый фильтр, жанры по «ИЛИ» и порядок по числу совпадений, `exclude_genres`, исключение оценённых и `exclude_ids`, порог 100, `UNKNOWN_GENRE`, неверные параметры; время на 10 000 и 100 000 фильмов | фикстура 20 фильмов + синтетика |
| TS-DB-05 | Профиль: пустой, после 5 оценок (числа из ADR-013), изменение после новой оценки, `limit` не влияет | фикстура |
| TS-DB-06 | Оценка 1–10, повторная оценка, закрытие выбора, `close_choice`, один `pending` на пользователя, история | фикстура |
| TS-DB-07 | Погода: известный и неоднозначный город, все группы кодов WMO, кэш 30 мин, тайм-аут 3 с → `None` | мок Open-Meteo |
| TS-DB-08 | Удаление: все таблицы пользователя пусты, `deleted_counts` верны, каталог не затронут, в журнале нет текстов | фикстура |
| TS-DB-09 | Одновременная работа приложения и загрузки: чтение не блокируется, запись ждёт ≤ 5 с | фикстура |
| TS-DB-10 | Схема: `alembic upgrade head` и `downgrade -1`; внешние ключи; `CHECK`-ограничения; наличие индексов | пустая база |
| TS-DB-11 | Возрастная маркировка: `RU`, пустая `RU` → `US` (все строки таблицы), `adult = true` → `18+`, пусто → `NULL` | мок TMDB |
