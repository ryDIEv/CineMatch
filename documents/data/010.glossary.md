# 010 — Глоссарий

*CineMatch. Модуль данных* | [оглавление модуля](README.md)

| Термин | English | Определение |
|---|---|---|
| Каталог | Catalog | Локальная копия метаданных фильмов, загруженная из TMDB |
| Загрузка каталога | Catalog ingestion | Получение фильмов из TMDB, нормализация и запись в базу; выполняется скриптом вне диалога |
| Нормализация | Normalization | Приведение ответа TMDB к схеме базы: год из даты выхода, жанры во внутренние ID, первые 10 актёров, возрастная маркировка |
| UPSERT | Upsert | Вставка записи или обновление существующей с тем же `tmdb_id` |
| Порог голосов | Vote threshold | Минимальное число голосов, ниже которого фильм не попадает в выдачу |
| Возрастная маркировка | Age rating | Возрастное ограничение фильма для России (0+…18+) из данных TMDB |
| Постер | Poster | Изображение фильма на сервере `image.tmdb.org`; в базе хранится только путь |
| Профиль предпочтений | Preference profile | Веса жанров и актёров, рассчитанные из оценок при запросе; отдельно не хранится |
| Холодный старт | Cold start | У пользователя нет оценок, профиль пуст |
| Инструмент | Tool | Функция, которую вызывает модель агента; параметры проверяются модулем данных |
| Служебная функция | Service function | Функция, которую вызывает код (оркестратор, API-слой, скрипт) |
| Ожидающий выбор | Pending choice | Выбранный фильм, по которому ещё нет оценки |
| Режим WAL | Write-Ahead Logging | Режим журналирования SQLite, позволяющий читать базу во время записи |
| Каскадное удаление | Cascade delete | Удаление зависимых записей вместе с записью пользователя |
| Геокодинг | Geocoding | Поиск координат и страны по названию города |
| Миграция | Migration | Пронумерованный SQL-файл, изменяющий схему базы |

Термины агентного слоя — в [глоссарии модуля агентов](../agents/010.glossary.md).

### Будущий функционал

| Термин | Определение |
|---|---|
| Новинка | Новый фильм или серия, вышедшие после последней проверки |
| Подписка | Желание пользователя получать уведомления о новинках конкретного сериала или фильма |
