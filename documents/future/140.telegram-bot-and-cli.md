# 140 — Telegram-бот и CLI

*CineMatch. Модуль интерфейса* | [оглавление модуля](../ui/README.md)

Два тонких интерфейса над единым ядром: **Telegram-бот** (aiogram 3) и **консольный CLI** (typer + rich). Логика работает только в модуле данных — интерфейсы только отдают состояние пользователя, получают его, показывают подборки и сохраняют оценки.

## 1. Telegram-бот

### 1.1 Диалог по сценариям (FSM)

| Этап | Что делает бот | Куда идёт запрос |
|---|---|---|
| `consent` | Показывает согласие на обработку данных, кнопки «Принимаю» / «Не сейчас» | `POST /api/v1/consent` |
| `onboarding` | Ввод города с вариантами из `/api/v1/cities` | `GET /api/v1/cities` |
| `dialog` | Считывает настроение, время, компанию, свободное время; показывает подборку; принимает реакцию | `POST /api/v1/messages` |
| `confirm_delete` | Подтверждение удаления данных | `POST /api/v1/me` |
| `eval` / `choice` | Ввод оценки от 1 до 10, отметка о просмотренном фильме через фразу «посмотрел X, на N» | `POST /api/v1/messages` |

Инлайн-кнопки используются только для ответов типа да/нет, выбор города и отправка сообщения. Вся остальная работа идёт через текст.

### 1.2 Фразовые команды

| Фраза | Реакция |
|---|---|
| «посмотрел X, на N» | `save_rating` с `source=manual` |
| «не смотрел» по неоценённому выбору | `close_choice` со статусом `dismissed` |
| «Дюна (2021), 8» / «Дюна 2021 — 8» | поиск фильма, сохранение оценки |
| «без ужасов, на 2 часа, с друзьями» | `extract_context` + подборка |

### 1.3 Состояние пользователя

- Погода подтягивается через Open-Meteo по городу, выбранному на этапе `onboarding`.
- История оценок и веса жанров подтягиваются из модуля данных.
- Логика вынесена в ядро данных — бот ничего не знает о правилах подбора и не повторяет их.

## 2. Консольный интерфейс

### 2.1 Структура

| Меню | Действие |
|---|---|
| 1. Подбор фильма | Ввод настроения, времени, компании, города через `typer`; вывод подборки в виде таблицы |
| 2. История оценок | Список оценённых фильмов |
| 3. Профиль | Веса жанров и актёров, `ratings_count` |
| 4. Удалить данные | Подтверждение, `DELETE /api/v1/me` |
| 5. Сохранить оценку | Ввод фильма и оценки по 1–10 |
| 6. Выход | Завершение |

### 2.2 Ввод

Использует `typer.prompt` и `rich.prompt`. Наиболее частые биты:

- выбор города: `prompt.choice` со списком из `/api/v1/cities`;
- настройство подбора: текст + парсинг фраз вида «без ужасов, на 2 часа, с друзьями»;
- вывод подборки: `rich.table` с колонками постер, название, год, длительность, рейтинг, возрастная маркировка, жанры, объяснение.

### 2.3 Отображение подборки

```
⟠  Подбор (Город: Казань · 20:00 · с друзьями · без ужасов)
1. Тихий дом у моря        2014 · 1 ч 38 мин · ★ 7,8 · 12+
   драма, комедия — спокойная тёплая история для дождливого вечера
2. ... (продолжение)
3. ...
```

## 3. Общие правила

1. **Единое ядро.** Код логики не дублируется. Оба интерфейса только вызывают функции ядра и отображают результат.
2. **Тонкие слои.** Ничего стратегического в боте и CLI нет: всё — запросы, отрисовка, обработка ошибок.
3. **Метрики.** В ориентиры `T_dec`, клики, число вызовов модели и числа инструментов фиксируются в модуле логирования и отдаются в `/api/v1/metrics`.
4. **Ошибки.** При ошибке интерфейс не падает: показывает сообщение и предлагает восстановить состояние (выбрать город, повторить запрос).
5. **Отказ от посторонних тем.** В боте и CLI работа только с фильмом и вечером, если явно не разрешено иным модулям.

### 4. Будущий функционал

Теперь Telegram-бота как отдельную активную карточку, панель отладки интерфейсов, локальный режим отдачи состояния.
