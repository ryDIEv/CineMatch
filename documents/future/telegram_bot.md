# Telegram-бот (aiogram 3)

|*CineMatch. Модуль интерфейса* | [оглавление](../ui/README.md)

Реализация интерактивного диалога с пользователем через Telegram. Всё поведение боту явно ограничено: он не принимает решение, а лишь проводит диалог, проверяет состояние и вызывает делающий это ядро (агент + инструменты).

## 1. Кому что принадлежит

| Что | Ответственный | Ограничения |
|---|---|---|
| Согласие на обработку данных | Код (ориентиры сессии) | Модель не видит и не управляет |
| Выбор города | Код (`resolve_city`) | — |
| Удаление данных | Код (`delete_user_data`) | Только по `yes` на этапе `confirm_delete` |
| Лимиты (8 вызовов модели, 10 действий/сообщение) | Код (счётчики в оркестраторе) | Модель не управляет |
| Подбор фильма, оценки, профиль | Ядро + агент (Pydantic AI) | — |

## 2. Меню состояний (FSM)

| Этап | Бот отвечает | Пользователь отвечает |
|---|---|---|
| `consent` | Текст согласия + кнопки «Принимаю» / «Не сейчас» | Нажатие или текст |
| `onboarding` | Ввод города, частичный список из `/api/v1/cities`, `choose_city` | Выбор одного из вариантов или указанный текстом город |
| `dialog` | Напоминание о настроении, времени, компании; подборка 3 фильмов; реакция на подборку | Текст: «без ужасов, на 3 часа…», нажатие на карточку, «расхотелось» |
| `confirm_delete` | Текст удаления + кнопки «Да, удалить» / «Отмена» | Нажатие или текст |
| `eval` | Показ оценённого фильма с запросом оценки 1–10, или фраза «посмотрел X» | От 1–10, или фраза с названием и оценкой |

## 3. Инструменты бота

1. `send_message(text, reply_markup)` — отправка сообщения с кнопками.
2. `send_message_stream(text)` — показ хода работы по событиям (SSE → Telegram).
3. `register_handlers(dispatcher)` — регистрация FSM-хаендлеров: `consent`, `onboarding`, `dialog`, `confirm_delete`, `eval`.
4. `build_inline_keyboard(stage, state, actions)` — токенизация ответов в набор кнопок.
5. `set_consent(user_id, accepted)` — вызов ядра.
6. `resolve_city(user_id, text)` — вызов ядра.
7. `handle_message(user_id, text)` — основной эндпоинт: классификатор → ядро → ответ боту.

## 4. Правила

- Бот может выдать подборку не более чем за 3 сообщения до первого результата.
- Не более двух уточняющих вопросов до подборки.
- Город выбирается первого раза; затем бот не спрашивает.
- Все введённые пользователем данные (кроме согласия) сохраняются в базе как `source=manual`.
- Ответы боту идут через поток SSE; клиент показывает ход работы в реальном времени.

## 5. Внешние зависимости

- `aiogram 3` — FSM и inline-кнопки.
- `aiohttp` — получение SSE от `/api/v1/messages` и `/api/v1/health`.
- `httpx` — вызов точек API-слоя.
- Локали: русский язык; все сообщения — только в русском.
