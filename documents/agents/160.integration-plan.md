# 160 — Integration Plan

*CineMatch. Модуль ИИ-агентов* | [оглавление модуля](README.md)

Сроки согласованы с [дорожной картой](../../docs/roadmap.md). Каждый критерий проверяем: его можно предъявить, не спрашивая автора.

| № | Интеграция | С кем | Срок | Критерий готовности |
|---|---|---|---|---|
| 0 | Решения по противоречиям и общие контракты | все модули | 11.11 | приняты ADR-030…ADR-040 и ADR-043…ADR-046; [contracts.md](../overall/contracts.md) 0.4.0 и [config.md](../overall/config.md) в `main` |
| 1 | Контракты в коде (`cinematch/overall/contracts.py`, `errors.py`) | все модули | до 12.11 | модели совпадают с [contracts §2](../overall/contracts.md#2-модели); `pytest` на сериализацию проходит |
| 2 | Агент ↔ RouterAI | внешний сервис | до 15.11 | запрос с вызовом инструмента проходит; в журнале есть `tokens_in`, `tokens_out`, `duration_ms`; ключ не в трассе |
| 3 | Агент на заглушках модуля данных | модуль данных | до 15.11 | эталонный диалог «Подбор и выбор» ([115 §3](115.live-prototype.md#3-подбор-и-выбор)) проходит, трасса содержит `find_movies` |
| 4 | API-слой ↔ `handle_user_turn` | модуль интерфейса | до 19.11 | `/start`, согласие, сообщение и поток SSE работают из браузера; порядок событий — [contracts §3](../overall/contracts.md#3-сообщения-о-ходе-работы) |
| 5 | Реальные инструменты модуля данных | модуль данных | до 22.11 | TS-AG-02…TS-AG-05 на реальном каталоге; 0 фильмов вне каталога |
| 6 | Промпты и модель | модуль агентов | до 22.11 | 8 из 10 эталонных пар [125 §7](125.prompts.md#7-эталонные-пары-сообщение--ожидаемый-agentoutput) совпадают по `kind` и числу `movie_ids` |
| 7 | Демо MVP | все | 29.11 | TS-AG-01…TS-AG-12 проходят в Docker Compose; `docker compose up` открывает страницу |

Правила:

1. Интеграция считается выполненной только по критерию, а не по факту разговора.
2. Изменение контракта после шага 1 — новый PR с ADR и повторным прогоном затронутых проверок.
3. Заглушки модуля данных остаются доступны до шага 5: агент не блокируется ожиданием реального каталога.

### Будущий функционал

Подключение Telegram-бота и агента-планировщика после MVP.
