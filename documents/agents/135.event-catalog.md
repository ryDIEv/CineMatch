# 135 — Event Catalog

*CineMatch. Модуль ИИ-агентов* | [оглавление модуля](README.md)

Брокер сообщений не используется: модули работают в одном процессе. События пишутся в журнал; часть из них уже отражена записями в базе (выбор, оценка, удаление), отдельной шины нет.

Набор согласован с [040](040.event-storming.md): каждое доменное событие оттуда либо входит в таблицу, либо явно помечено как производное. Схемы — [140](140.event-schema.md).

| Событие | Издатель | Обработчики | Триггер | Критичность |
|---|---|---|---|---|
| `ConsentAccepted` | Оркестратор | Журнал, запись пользователя | `set_consent(True)` | высокая |
| `CitySaved` | Оркестратор | Журнал, запись пользователя | `save_user_settings` | средняя |
| `RequestClassified` | Классификатор | Журнал | сообщение на этапе `dialog` | низкая |
| `ContextExtracted` | Агент (`extract_context`) | Журнал | контекст вечера получен | низкая |
| `CandidatesFound` | Агент (`find_movies`) | Журнал | поиск вернул результат | низкая |
| `RecommendationShown` | Оркестратор (после проверки) | Журнал, трасса ответа | подборка показана | средняя |
| `AlternativesRequested` | Агент | Журнал | просьба о других вариантах | низкая |
| `RecommendationStopped` | Агент | Журнал | отказ от подбора | низкая |
| `MovieChosen` | Модуль данных (`save_choice`) | Журнал, таблица выборов | выбор фильма | высокая |
| `RatingRequested` | Оркестратор | Журнал | `/start` с неоценённым выбором | низкая |
| `RatingSaved` | Модуль данных (`save_rating`) | Журнал, таблица оценок | UC-5, UC-6 | высокая |
| `WatchMarkedManually` | Агент | Журнал | отметка просмотренного | средняя |
| `OffTopicRejected` | Оркестратор | Журнал | UC-8 | низкая |
| `GuardrailTriggered` | Оркестратор | Журнал | ответ не прошёл проверку, превышен лимит | средняя |
| `ProgressEmitted` | Оркестратор | Журнал (уровень debug) | отправлено событие `progress` | низкая |

| `UserDataDeleted` | Модуль данных (`delete_user_data`) | Журнал | подтверждение удаления (UC-7) | высокая |

Правила:

1. Событие из этой таблицы обязано иметь схему в [140](140.event-schema.md). Событий «в каталоге, но без схемы» нет.
2. `ProgressEmitted` пишется на уровне debug и не хранится в базе: это диагностика задержек, а не история.
3. `SessionBusy` не является ошибкой пользователя: текст ответа — `SESSION_BUSY` из [contracts §6](../overall/contracts.md#6-ошибки).
4. Тексты сообщений и промпты в события не попадают (NFR-AG-15).
5. Имена событий в коде — из этой таблицы; переименование — изменение контракта.

### Будущий функционал

`ReminderScheduled`, `ReminderSent`, `SubscriptionCreated`, `NewReleasesDigestPrepared` — с асинхронной доставкой через Telegram-бота; появятся вместе со схемами.
