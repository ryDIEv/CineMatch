# 135 — Event Catalog

*CineMatch. Модуль ИИ-агентов* | [оглавление модуля](README.md)

Брокер сообщений не используется: модули работают в одном процессе. События фиксируются в журнале и, где нужно, записями в базе данных.

| Событие | Издатель | Обработчики | Триггер | Критичность |
|---|---|---|---|---|
| `IntentClassified` | Классификатор | Журнал | Сообщение на этапе `idle` | низкая |
| `RecommendationShown` | Рекомендатель | Журнал, трасса ответа | Подборка показана | средняя |
| `MovieChosen` | Оркестратор | Модуль данных (запись выбора) | Реакция `select` | высокая |
| `RecommendationStopped` | Рекомендатель | Журнал | Реакция `stop` | низкая |
| `RatingSaved` | Компаньон | Модуль данных | UC-5, UC-6 | высокая |
| `OffTopicRejected` | Защита диалога | Журнал | UC-8 | низкая |
| `UserDataDeleted` | Оркестратор | Модуль данных | UC-7 | высокая |

### Будущий функционал

`ReminderScheduled`, `NewReleasesDigestPrepared` — с асинхронной доставкой через Telegram-бота.
