# 135 — Event Catalog

*CineMatch. Модуль ИИ-агентов* | [оглавление модуля](README.md)

Брокер сообщений не используется: модули работают в одном процессе. События фиксируются в журнале и, где нужно, записями в базе данных.

| Событие | Издатель | Обработчики | Триггер | Критичность |
|---|---|---|---|---|
| `RequestClassified` | Классификатор | Журнал | Сообщение на этапе `dialog` | низкая |
| `RecommendationShown` | Оркестратор (после проверки ответа агента) | Журнал, трасса ответа | Подборка показана | средняя |
| `MovieChosen` | Модуль данных (`save_choice`, вызов агента) | Журнал | Выбор фильма | высокая |
| `RecommendationStopped` | Агент | Журнал | Отказ от подбора | низкая |
| `RatingSaved` | Модуль данных (`save_rating`, вызов агента) | Журнал | UC-5, UC-6 | высокая |
| `OffTopicRejected` | Оркестратор | Журнал | UC-8 | низкая |
| `GuardrailTriggered` | Оркестратор | Журнал | Ответ не прошёл проверку, превышен лимит | средняя |
| `UserDataDeleted` | Модуль данных (`delete_user_data`) | Журнал | Подтверждение удаления в оркестраторе (UC-7) | высокая |

### Будущий функционал

`ReminderScheduled`, `NewReleasesDigestPrepared` — с асинхронной доставкой через Telegram-бота.
