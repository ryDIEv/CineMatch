# 130 — API Contracts

*CineMatch. Модуль ИИ-агентов* | [оглавление модуля](README.md)

Модуль работает в процессе backend и вызывается API-слоем как функция Python. Версия контракта — `0.2.0` (semver).

**Вход**

```python
handle_user_turn(user_id: str, message: str, movie_id: int | None = None) -> AgentResponse
```

`movie_id` передаётся, если сообщение сформировано нажатием на карточку; агент использует его как подсказку, но решение о реакции принимает сам.

**Выход — AgentResponse**

```json
{
  "contract_version": "0.2.0",
  "type": "recommendations",
  "text": "За окном дождь — вот три спокойных фильма до полутора часов:",
  "movies": [
    {
      "movie_id": 101,
      "title": "Тихий дом у моря",
      "year": 2014,
      "runtime": 98,
      "rating": 7.8,
      "age_rating": "12+",
      "genres": ["Драма", "Комедия"],
      "poster_url": "https://image.tmdb.org/t/p/w342/abc.jpg",
      "reason": "Спокойная тёплая история, в самый раз для дождливого вечера."
    }
  ],
  "trace": [
    {"step": "Контекст", "action": "extract_context()", "summary": "устал, 90 минут, один, без ужасов"},
    {"step": "Погода", "action": "get_weather()", "summary": "Москва, дождь, +9°"},
    {"step": "Поиск", "action": "find_movies(жанры: драма, комедия; длительность ≤ 100)", "summary": "найдено 14 фильмов"}
  ],
  "stage": "dialog"
}
```

Ошибка: `{"type": "error", "text": "Не удалось получить ответ модели. Попробуйте ещё раз.", "error_code": "LLM_UNAVAILABLE", "stage": "dialog"}`.

| `error_code` | Причина |
|---|---|
| `LLM_UNAVAILABLE` | RouterAI не ответил после повтора |
| `LLM_INVALID_OUTPUT` | Модель дважды вернула ответ не по схеме или с фильмом вне результатов поиска |
| `LIMIT_EXCEEDED` | Превышен лимит вызовов модели на сообщение |
| `DATA_UNAVAILABLE` | Ошибка модуля данных |
| `INPUT_TOO_LONG` | Сообщение длиннее 1000 символов |

**Инструменты.** Описываются функциями Python с аннотациями типов; Pydantic AI строит из них JSON Schema для API, совместимого с OpenAI. Пример схемы, которую получает модель:

```json
{
  "type": "function",
  "function": {
    "name": "find_movies",
    "description": "Найти фильмы по критериям. Возвращает фильмы, отсортированные по рейтингу; уже показанные и оценённые исключаются автоматически.",
    "parameters": {
      "type": "object",
      "properties": {
        "genres": {"type": "array", "items": {"type": "string"}},
        "year_from": {"type": "integer", "minimum": 1900},
        "year_to": {"type": "integer", "maximum": 2030},
        "min_rating": {"type": "number", "minimum": 0, "maximum": 10},
        "max_runtime": {"type": "integer", "minimum": 30},
        "limit": {"type": "integer", "minimum": 3, "maximum": 30, "default": 15}
      },
      "required": ["genres"]
    }
  }
}
```

| Инструмент | Параметры от модели | Подставляет код |
|---|---|---|
| `extract_context` | `message` | — |
| `get_user_ratings` | `limit` | `user_id` |
| `get_user_profile` | — | `user_id` |
| `get_weather` | — | `user_id` |
| `find_movies` | `genres`, `year_from`, `year_to`, `min_rating`, `max_runtime`, `limit` | `user_id`, `exclude_ids` |
| `get_movie_with_credits` | `movie_id` | — |
| `search_movie` | `title`, `year` | — |
| `save_choice` | `movie_id` | `user_id`; проверка по `last_shown_ids` |
| `save_rating` | `movie_id`, `rating`, `mood_match` | `user_id`, `source` |
| `close_choice` | — | `choice_id` из `pending` |

Сигнатуры и результаты функций модуля данных — в [130 модуля данных](../data/130.api-contracts.md). Ошибка инструмента возвращается модели как результат (`{"error": {...}}`), чтобы модель могла исправить вызов.

### Будущий функционал

Параметр `source` во входе (`web`, `telegram`) для различий в поведении интерфейсов; инструменты агента-планировщика.
