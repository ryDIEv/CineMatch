# 150 — Component Diagram

*CineMatch. Модуль ИИ-агентов* | [оглавление модуля](README.md)

![Компоненты модуля](diagrams/150-components.svg)

| Компонент | Технология | Ответственность |
|---|---|---|
| Оркестратор | Python | Этапы диалога, сессия, служебные действия (согласие, город, удаление) |
| Классификатор намерений | LLM, structured output | Намерение на этапе `idle` |
| Защита диалога | Python, JSON Schema | Длина ввода, проверка ответов модели, отказы |
| Агенты (3) | LLM + tool use | Распознавание состояния, подбор, оценки |
| Реестр инструментов | Python | Схемы, права агентов, подстановка `user_id` и исключений |
| Клиент LLM | Python, SDK, совместимый с OpenAI | Запросы к OpenRouter, повтор, учёт токенов |
| Промпты | Текстовые файлы | Системные промпты агентов, версионируются в Git |
| Трасса решений | Python | Сбор шагов агентов для ответа и журнала |
