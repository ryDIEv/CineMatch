# 095 — Traceability Matrix

*CineMatch. Модуль ИИ-агентов* | [оглавление модуля](README.md)

**Функциональные требования**

| ID | Требование | Источник |
|---|---|---|
| FR-AG-01 | Вход `handle_user_turn(user_id, message, movie_id=None)`, ответ `AgentResponse` | Vision |
| FR-AG-02 | До согласия модуль не сохраняет данные и не вызывает модель | ADR-002 |
| FR-AG-03 | Онбординг: город с подтверждением найденного варианта | ADR-002 |
| FR-AG-04 | Каждое сообщение на этапе `dialog` проходит классификатор запросов с закрытым перечнем | ADR-005 |
| FR-AG-05 | Агент извлекает контекст вечера, спрашивает недостающее (не более двух вопросов), учитывает историю оценок и погоду | ADR-026 |
| FR-AG-06 | Агент получает фильмы только через `find_movies`; код проверяет, что показанные фильмы есть в результатах | ADR-003 |
| FR-AG-07 | Каждая подборка содержит трассу решений | ADR-009 |
| FR-AG-08 | Агент распознаёт реакцию на подборку (выбор, другие варианты, отказ) и вызывает нужные инструменты | ADR-007 |
| FR-AG-09 | Неоценённый выбор предлагается оценить при следующем визите | Решение команды |
| FR-AG-10 | Отметка «посмотрел X» с поиском фильма и оценкой 1–10 | Решение команды |
| FR-AG-11 | Удаление данных по фразе пользователя после подтверждения; выполняет только код | ADR-002 |
| FR-AG-12 | Отказ на сообщения не по теме и небезопасные без вызова агента | ADR-005 |

**Тестовые сценарии** (эталонные диалоги — в [115](115.live-prototype.md))

| ID | Проверка |
|---|---|
| TS-AG-01 | Первый визит: согласие, отказ, город (один и несколько вариантов) |
| TS-AG-02 | Подбор: всё в одном сообщении; по шагам; без погоды |
| TS-AG-03 | Реакции: выбор текстом и карточкой, другие варианты по тем же и новым критериям, отказ |
| TS-AG-04 | Оценка при следующем визите; ответ «не смотрел» |
| TS-AG-05 | Отметка просмотренного: однозначное и неоднозначное название, без оценки |
| TS-AG-06 | Удаление данных с подтверждением и с отказом |
| TS-AG-07 | 20 сообщений не по теме и попыток внедрения инструкций |
| TS-AG-08 | Время ответа и расход токенов на 10 полных подборах |
| TS-AG-09 | Тест модели: 30 эталонных диалогов; доля корректных вызовов инструментов, доля ответов по схеме, число фильмов вне каталога |
