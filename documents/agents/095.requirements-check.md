# 095 — Traceability Matrix

*CineMatch. Модуль ИИ-агентов* | [оглавление модуля](README.md)

**Функциональные требования**

| ID | Требование | Источник |
|---|---|---|
| FR-AG-01 | Вход `handle_user_turn(user_id, message)`, ответ `AgentResponse` | Vision |
| FR-AG-02 | До согласия модуль не сохраняет данные и не выполняет других действий | Решение команды |
| FR-AG-03 | Онбординг: город с подтверждением найденного варианта | Решение команды |
| FR-AG-04 | Намерение на этапе `idle` определяется классификатором из закрытого перечня | ADR-005 |
| FR-AG-05 | Распознаватель извлекает сказанное, спрашивает недостающее и 1–2 уточнения, учитывает историю и погоду | Vision |
| FR-AG-06 | Рекомендатель получает фильмы только через `find_movies`, показывает три с объяснением | ADR-003 |
| FR-AG-07 | Каждая подборка содержит трассу решений | ADR-009 |
| FR-AG-08 | Реакция относится к `select`, `another`, `stop`, `off_topic` | ADR-007 |
| FR-AG-09 | Неоценённый выбор предлагается оценить при следующем визите | Решение команды |
| FR-AG-10 | Отметка «посмотрел X» с поиском фильма и оценкой 1–10 | Решение команды |
| FR-AG-11 | Удаление данных по фразе пользователя после подтверждения | Решение команды |
| FR-AG-12 | Отказ на сообщения не по теме | Vision |

**Тестовые сценарии** (ручная проверка; эталонные диалоги — в [115](115.live-prototype.md))

| ID | Проверка |
|---|---|
| TS-AG-01 | Первый визит: согласие, отказ, город (один и несколько вариантов) |
| TS-AG-02 | Подбор: всё в одном сообщении; по шагам; без погоды |
| TS-AG-03 | Реакции: выбор текстом и карточкой, другие варианты из пула и новым поиском, отказ |
| TS-AG-04 | Оценка при следующем визите; ответ «не смотрел» |
| TS-AG-05 | Отметка просмотренного: однозначное и неоднозначное название, без оценки |
| TS-AG-06 | Удаление данных с подтверждением и без |
| TS-AG-07 | 20 сообщений не по теме и попыток внедрения инструкций |
| TS-AG-08 | Время ответа и расход токенов на 10 полных подборах |
