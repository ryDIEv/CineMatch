# 140 — Event Schema

*CineMatch. Модуль данных* | [оглавление модуля](README.md)

Общая форма записи журнала (`event`, `schema_version`, `event_id`, `user_id`, `occurred_at`, `payload`) — [140 модуля агентов](../agents/140.event-schema.md); здесь не дублируется. Ниже — только события, которые вводит модуль данных; схемы общих событий (`ConsentAccepted`, `CitySaved`, `MovieChosen`, `RatingSaved`, `UserDataDeleted`) остаются в [140 агентов](../agents/140.event-schema.md) и здесь не повторяются.

## 1. События модуля данных

| Событие | Поля `payload` |
|---|---|
| `CatalogLoadStarted` | `load_id` (int), `pages` (int), `from_year` (int), `min_votes` (int), `resumed` (bool) |
| `MoviesUpserted` | `load_id` (int), `page` (int), `movies` (int), `inserted` (int), `updated` (int) |
| `CatalogLoadFinished` | `load_id` (int), `status` (`completed`, `partial`, `failed`), `pages_done` (int), `movies_upserted` (int), `movies_skipped` (int), `last_page` (int), `duration_s` (number) |
| `SessionExpired` | `sessions` (int) — сколько строк удалил `purge_expired` |

Пример:

```json
{
  "event": "CatalogLoadFinished",
  "schema_version": 1,
  "event_id": "6f1c1d2e-8a52-4d0b-9a4f-1b7c2e5d3a90",
  "user_id": null,
  "occurred_at": "2026-11-15T19:42:11Z",
  "payload": {
    "load_id": 3,
    "status": "completed",
    "pages_done": 500,
    "movies_upserted": 9987,
    "movies_skipped": 13,
    "last_page": 500,
    "duration_s": 412.8
  }
}
```

## 2. Правила

1. `schema_version` начинается с 1; добавление поля — та же версия, удаление или смена типа — новая версия и запись в [145](145.architecture-decisions.md).
2. `user_id` — `null` для событий загрузки и пакетной очистки: событие не относится к одному пользователю.
3. `MoviesUpserted` пишется на каждую закоммиченную порцию; по нему видно, на какой странице оборвалась загрузка, если `CatalogLoadFinished` не появился.
4. В `payload` нет названий фильмов, текстов городов, оценок пользователя и ключа TMDB — только идентификаторы и счётчики (NFR-DB-10).
5. Одно событие — одна строка JSON; отдельной схемы на событие не заводится.

### Будущий функционал

Схема `ReleaseDetected`: `tmdb_id`, `kind`, `release`, `subscribers`.
