# 140 — Event Schema

*CineMatch. Модуль ИИ-агентов* | [оглавление модуля](README.md)

Общие поля записи журнала событий (используются всеми модулями). События и их издатели — [135](135.event-catalog.md).

```json
{
  "event": "MovieChosen",
  "schema_version": 1,
  "event_id": "uuid",
  "user_id": "web:local",
  "occurred_at": "2026-11-08T21:15:00+03:00",
  "payload": {}
}
```

| Событие | Поля `payload` |
|---|---|
| `ConsentAccepted` | `source` (`web`, `chat`) |
| `CitySaved` | `city` (string), `region` (string или null), `country` (string) |
| `RequestClassified` | `class` (string), `duration_ms` (int) |
| `ContextExtracted` | `mood`, `energy`, `company` (string или null), `available_minutes` (int или null), `genres_count` (int) |
| `CandidatesFound` | `criteria` (object: `genres`, `year_from`, `year_to`, `min_rating`, `max_runtime`), `found` (int) |
| `RecommendationShown` | `movie_ids` (int[0–3]), `round` (int), `tool_calls` (int) |
| `AlternativesRequested` | `changed` (bool), `round` (int) |
| `RecommendationStopped` | `rounds` (int) |
| `MovieChosen` | `movie_id` (int), `via` (`text`, `card`) |
| `RatingRequested` | `choice_id` (int), `days_since` (int) |
| `RatingSaved` | `movie_id` (int), `rating` (1–10), `mood_match` (`yes`, `partly`, `no`, null), `source` (`after_choice`, `manual`) |
| `WatchMarkedManually` | `movie_id` (int), `rating` (1–10) |
| `OffTopicRejected` | `class` (`off_topic`, `unsafe`) — без текста сообщения |
| `GuardrailTriggered` | `rule` (`schema`, `movie_not_found`, `tool_not_allowed`, `limit`), `retried` (bool) |
| `ProgressEmitted` | `step` (`classify`, `tool`, `check`), `duration_ms` (int) |
| `SessionBusy` | `active_stage` (string), `waited_ms` (int) |
| `UserDataDeleted` | `deleted_counts` (object: `user_choices`, `user_ratings`, `sessions`) |

Правила:

1. Ключ разбиения не требуется (брокера нет). Совместимость: поля только добавляются; несовместимое изменение — новый `schema_version` и запись в [145](145.architecture-decisions.md).
2. `rule = tool_not_allowed` — правило проверки инструментов, а не код ошибки; коды ошибок — [overall/contracts.md §6](../overall/contracts.md#6-ошибки).
3. `movie_ids` в `RecommendationShown` может содержать 1–2 элемента: столько, сколько показано при нехватке результатов.
4. Персональные данные, тексты сообщений и промпты в `payload` не попадают.
5. Запись события — одна строка JSON; формат и обязательные поля описаны здесь, отдельной схемы на каждое событие не заводится.
