# 010 — Глоссарий

*CineMatch. Модуль ИИ-агентов* | [оглавление модуля](README.md)

| Термин | English | Определение |
|---|---|---|
| ИИ-агент | AI agent | Компонент, в котором языковая модель сама выбирает следующее действие (вопрос пользователю, вызов инструмента, завершение), получает результат и при необходимости корректирует действие |
| Оркестратор | Orchestrator | Код, который принимает сообщение, определяет этап диалога и передаёт сообщение нужному агенту. Агентом не является |
| Намерение | Intent | Цель сообщения на этапе `idle`: подобрать фильм, отметить просмотр, изменить город, удалить данные, не по теме |
| Классификатор намерений | Intent classifier | Вызов модели, относящий сообщение к одному значению из закрытого перечня намерений |
| Инструмент | Tool | Функция модуля данных, которую модель может вызвать через tool use |
| Вызов инструмента | Tool call | Ответ модели вида «вызови функцию X с параметрами Y» вместо текста |
| Вектор состояния | State vector | Структурированное описание состояния пользователя: настроение, энергия, свободное время, компания, пожелания, погода |
| Профиль предпочтений | Preference profile | Веса жанров и актёров, рассчитанные из оценок пользователя |
| Критерии поиска | Search criteria | Параметры поиска фильмов, выбранные агентом: жанры, годы, минимальный рейтинг, максимальная длительность |
| Пул кандидатов | Candidate pool | Найденные по критериям фильмы, отсортированные по рейтингу; показываются по три |
| Подборка | Recommendation set | Три фильма с объяснением выбора |
| Реакция на подборку | Reaction | Ответ на подборку, отнесённый к одному из вариантов: `select` (выбор), `another` (другие варианты), `stop` (отказ), `off_topic` (не по теме) |
| Выбор | Choice | Фильм, который пользователь решил посмотреть; ждёт оценки |
| Оценка | Rating | Оценка просмотренного фильма от 1 до 10; после выбора или по собственной отметке пользователя |
| Трасса решений | Agent trace | Список действий агентов в ответе на сообщение: какие инструменты вызваны и с каким результатом; показывается пользователю |
| Этап диалога | Dialog stage | Состояние сессии, определяющее, какой агент обрабатывает следующее сообщение |
| Системный промпт | System prompt | Инструкция модели: роль агента, ограничения, формат ответа |
| Структурированный ответ | Structured output | Ответ модели строго в формате JSON по заданной схеме |
| Внедрение инструкций | Prompt injection | Попытка изменить поведение модели через текст пользователя |
| LLM-шлюз | LLM gateway | Сервис с единым API к моделям разных поставщиков; в проекте — OpenRouter |

### Будущий функционал

| Термин | Определение |
|---|---|
| Агент-планировщик | Агент, создающий напоминания и подписки по фразам пользователя |
| Подборка новинок | Периодический список новых фильмов, подходящих под профиль пользователя |
