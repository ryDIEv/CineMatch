# 010 — Глоссарий

*CineMatch. Модуль ИИ-агентов* | [оглавление модуля](README.md)

| Термин | English | Определение |
|---|---|---|
| ИИ-агент | AI agent | Компонент, в котором языковая модель сама выбирает следующее действие (вопрос пользователю, вызов инструмента, ответ), получает результат и продолжает до завершения задачи |
| Агент CineMatch | CineMatch agent | Единственный агент модуля: ведёт подбор, понимает реакции на подборку, принимает оценки |
| Оркестратор | Orchestrator | Код, который принимает сообщение, проверяет инварианты (согласие, город, подтверждение удаления, лимиты), вызывает классификатор и агента и проверяет ответ. Агентом не является |
| Инвариант | Invariant | Правило, которое выполняется всегда, независимо от ответа модели; реализуется кодом |
| Классификатор запросов | Request classifier | Вызов модели, относящий сообщение к одному значению из закрытого перечня: о кино, удаление данных, не по теме, небезопасный запрос |
| Инструмент | Tool | Функция, которую модель может вызвать через tool use |
| Вызов инструмента | Tool call | Ответ модели вида «вызови функцию X с параметрами Y» вместо текста |
| Агент как инструмент | Agent as tool | Отдельный вызов модели со структурированным ответом, оформленный как инструмент основного агента; в проекте — `extract_context` |
| Контекст вечера | Evening context | Структурированное описание ситуации пользователя: настроение, энергия, свободное время, компания, пожелания |
| Профиль предпочтений | Preference profile | Веса жанров и актёров, рассчитанные из оценок пользователя |
| Критерии поиска | Search criteria | Параметры `find_movies`, выбранные агентом: жанры, годы, минимальный рейтинг, максимальная длительность |
| Подборка | Recommendation set | Три фильма с объяснением выбора |
| Реакция на подборку | Reaction | Ответ на подборку: выбор фильма, просьба о других вариантах или отказ; распознаёт агент |
| Выбор | Choice | Фильм, который пользователь решил посмотреть; ждёт оценки |
| Оценка | Rating | Оценка просмотренного фильма от 1 до 10; после выбора или по собственной отметке пользователя |
| Трасса решений | Agent trace | Список действий агента в ответе на сообщение: какие инструменты вызваны и с каким результатом; показывается пользователю |
| Защитный механизм | Guardrail | Проверка или ограничение, не позволяющее модели выйти за рамки задачи |
| Системный промпт | System prompt | Инструкция модели: роль, правила, формат ответа |
| Структурированный ответ | Structured output | Ответ модели строго в формате JSON по заданной схеме |
| Внедрение инструкций | Prompt injection | Попытка изменить поведение модели через текст пользователя или данные |
| LLM-шлюз | LLM gateway | Сервис с единым API к моделям разных поставщиков; в проекте — RouterAI |

### Будущий функционал

| Термин | Определение |
|---|---|
| Агент-планировщик | Агент, создающий напоминания и подписки по фразам пользователя |
| Подборка новинок | Периодический список новых фильмов, подходящих под профиль пользователя |
