# 120 — Data Model: структуры модуля

*CineMatch. Модуль ИИ-агентов* | [оглавление модуля](README.md)

Физическую модель (таблицы) описывает [модуль данных](../data/120.data-model.md). Модуль агентов определяет структуры, которые создаёт и передаёт; все проверяются по JSON Schema.

**StateVector**

| Поле | Тип | Значения |
|---|---|---|
| `mood` | string | `calm`, `cheerful`, `sad`, `tired`, `tense`, `other` |
| `energy` | string | `low`, `medium`, `high` |
| `available_minutes` | integer | 30–600 |
| `company` | string | `alone`, `partner`, `friends`, `family` |
| `genre_wishes`, `genre_avoid` | array of string | жанры из справочника |
| `weather` | object или null | `{condition, temp_c}` |
| `notes` | string или null | ≤ 200 символов |

**SessionState** (хранится как JSON в таблице сессий)

| Поле | Тип | Описание |
|---|---|---|
| `stage` | string | этап из [050](050.entities.md) |
| `answers` | object | уже известные ответы |
| `clarifications_asked` | integer | 0–2 |
| `state_vector` | StateVector или null | |
| `recommendation` | object или null | `search_criteria`, `candidate_ids`, `cursor`, `shown_ids`, `searches_count` |
| `pending` | object или null | ожидаемое уточнение (выбор из нескольких фильмов, подтверждение удаления) |

**Intent:** `recommend`, `watched`, `settings`, `delete_data`, `help`, `off_topic`.

**Reaction:** `{reaction: select | another | stop | off_topic, selected_movie_id: int | null, new_wishes: string | null}`.

**AgentTrace:** `{agent: string, action: string, summary: string}` — действие в понятной пользователю форме, например `find_movies(жанры: комедия; длительность ≤ 100)` и `найдено 9 фильмов`.

### Будущий функционал

Структуры намерения `reminder` и запроса на напоминание `{due_at, text}`.
