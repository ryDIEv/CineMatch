# 120 — Data Model: структуры модуля

*CineMatch. Модуль ИИ-агентов* | [оглавление модуля](README.md)

Физическую модель (таблицы) описывает [модуль данных](../data/120.data-model.md). Модуль агентов определяет структуры, которые создаёт и передаёт; все описываются моделями Pydantic и проверяются по схеме.

**EveningContext** (результат `extract_context`)

| Поле | Тип | Значения |
|---|---|---|
| `mood` | string или null | `calm`, `cheerful`, `sad`, `tired`, `tense`, `other` |
| `energy` | string или null | `low`, `medium`, `high` |
| `available_minutes` | integer или null | 30–600 |
| `company` | string или null | `alone`, `partner`, `friends`, `family` |
| `genre_wishes`, `genre_avoid` | array of string | жанры из справочника |
| `notes` | string или null | ≤ 200 символов |

`null` означает, что пользователь об этом не сказал; агент решает, нужно ли спросить.

**SessionState** (хранится как JSON в таблице сессий)

| Поле | Тип | Описание |
|---|---|---|
| `stage` | string | `consent`, `onboarding`, `dialog`, `confirm_delete` |
| `pending` | object или null | неоценённый выбор `{choice_id, movie_id}` |
| `messages` | array | до 20 последних сообщений диалога в формате истории модели |
| `context` | EveningContext или null | последний извлечённый контекст |
| `last_shown_ids` | int[3] или пусто | фильмы последней подборки (для `save_choice`) |
| `shown_ids` | int[] | все фильмы, показанные в сессии (исключаются из поиска) |
| `clarifications_asked` | integer | вопросов в текущем подборе; при 2 агент получает указание подбирать без вопросов |

**RequestClass** (ответ классификатора): `cinema`, `delete_data`, `off_topic`, `unsafe`. На этапе `confirm_delete` классификатор отвечает из перечня `yes`, `no`.

**AgentOutput** (структурированный ответ агента): `{kind: question | recommendations | feedback_question | confirmation | message, text: string, movie_ids: int[0 или 3], reasons: string[0 или 3]}`.

**AgentTrace:** `{step: string, action: string, summary: string}` — действие в понятной пользователю форме, например `find_movies(жанры: комедия; длительность ≤ 100)` и `найдено 9 фильмов`.

### Будущий функционал

Класс запроса `reminder` и структура запроса на напоминание `{due_at, text}`.
