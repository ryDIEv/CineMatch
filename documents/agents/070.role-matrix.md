# 070 — RBAC

*CineMatch. Модуль ИИ-агентов* | [оглавление модуля](README.md)

**Роли.** В MVP одна роль — локальный пользователь. Каждый запрос выполняется от имени `user_id`, который определяет API-слой; модуль агентов работает только с данными этого пользователя.

| Действие | Пользователь |
|---|---|
| Подбор, реакция, оценка, отметка просмотра | ✅ |
| Изменение города | ✅ |
| Удаление своих данных | ✅ (после подтверждения) |
| Доступ к данным других пользователей | ❌ |

**Права на инструменты (принцип минимальных прав).** Модель может вызвать только инструменты из списка агента. Проверку выполняет реестр инструментов, поэтому вызов вне списка отклоняется, даже если текст пользователя убедил модель его сделать. `user_id` и списки исключений подставляет код, а не модель.

| Инструмент | Доступ | Ограничение, проверяемое кодом |
|---|---|---|
| `extract_context` | вызов модели | Ответ по схеме `EveningContext` |
| `get_user_ratings` | чтение | — |
| `get_user_profile` | чтение | — |
| `get_weather` | чтение | — |
| `find_movies` | чтение | Показанные и оценённые фильмы исключаются |
| `get_movie_with_credits` | чтение | — |
| `search_movie` | чтение | — |
| `save_choice` | запись | Только фильм из последней подборки |
| `save_rating` | запись | Оценка 1–10; фильм есть в каталоге |
| `close_choice` | запись | Только ожидающий выбор пользователя |

Служебные функции (`save_consent`, `resolve_city`, `save_user_settings`, `delete_user_data`, функции сессий) модели недоступны: их вызывает только оркестратор. Инструмента удаления данных у агента нет.

### Будущий функционал

Роли «пользователь Telegram» и «администратор»; инструменты агента-планировщика (`create_reminder`, `subscribe`, `search_series`).
