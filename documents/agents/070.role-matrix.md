# 070 — RBAC

*CineMatch. Модуль ИИ-агентов* | [оглавление модуля](README.md)

**Роли.** В MVP две роли: локальный пользователь и сопровождающий (участник команды). Каждый запрос пользователя выполняется от имени `user_id`, который определяет API-слой; модуль агентов работает только с данными этого пользователя.

| Действие | Пользователь | Сопровождающий |
|---|---|---|
| Подбор, реакция, оценка, отметка просмотра | да | — |
| Изменение города | да | — |
| Удаление своих данных | да (после подтверждения) | — |
| Загрузка каталога | нет | да, только CLI (`python -m scripts.load_catalog`) |
| Доступ к данным других пользователей | нет | нет (каталог не содержит пользовательских данных) |
| Просмотр агрегированной статистики | нет | нет (будущий функционал) |

Загрузка каталога не имеет HTTP-эндпоинта и не является инструментом агента: её выполняет скрипт в контейнере backend. Это же правило закрывает вопрос о том, почему «Сопровождающий» не появляется в API.

**Права на инструменты (принцип минимальных прав).** Модель может вызвать только инструменты из списка агента. Проверку выполняет реестр инструментов, поэтому вызов вне списка отклоняется, даже если текст пользователя убедил модель его сделать. `user_id` и `exclude_ids` подставляет код, а не модель (ADR-008).

| Инструмент | Доступ | Ограничение, проверяемое кодом | Ошибки модели |
|---|---|---|---|
| `extract_context` | вызов модели | ответ по схеме `EveningContext` | `INVALID_PARAM` |
| `get_user_ratings` | чтение | только `user_id` из запроса | `INVALID_PARAM` |
| `get_user_profile` | чтение | только `user_id` из запроса | — |
| `get_weather` | чтение | только город пользователя | — |
| `find_movies` | чтение | оценённые исключает модуль данных, показанные — `exclude_ids` | `INVALID_PARAM`, `UNKNOWN_GENRE` |
| `get_movie_with_credits` | чтение | — | `NOT_FOUND` |
| `search_movie` | чтение | до 5 совпадений | `INVALID_PARAM` |
| `save_choice` | запись | только фильм из `last_shown_ids` | `INVALID_PARAM`, `NOT_FOUND` |
| `save_rating` | запись | оценка 1–10; фильм есть в каталоге | `INVALID_PARAM`, `NOT_FOUND` |
| `close_choice` | запись | только ожидающий выбор пользователя | `NOT_FOUND` |

Сигнатуры и коды ошибок — [130](130.api-contracts.md#4-инструменты-агента) и [overall/contracts.md §7](../overall/contracts.md#7-инструменты).

Служебные функции (`save_consent`, `resolve_city`, `save_user_settings`, `delete_user_data`, функции сессий) модели недоступны: их вызывает только оркестратор. Инструмента удаления данных у агента нет.

## Будущий функционал

Роли «пользователь Telegram» и «администратор»; инструменты агента-планировщика (`create_reminder`, `subscribe`, `search_series`).
