# 110 — UI/UX: диалоговый дизайн

*CineMatch. Модуль ИИ-агентов* | [оглавление модуля](README.md)

Экраны проектирует [модуль интерфейса](../ui/110.ui-ux.md). Модуль агентов отвечает за содержание диалога.

| Принцип | Применение |
|---|---|
| Свободный текст | Пользователь пишет своими словами; агент не предлагает вариантов-кнопок |
| Не переспрашивать | Если в сообщении уже есть ответ (время, настроение), вопрос не задаётся |
| Один вопрос за раз | В сообщении не больше одного вопроса |
| Конкретные объяснения | Объяснение фильма ссылается на сказанное пользователем: «вы просили без ужасов», «на полтора часа» |
| Подтверждение действий | Сохранение оценки и выбора подтверждается: «Записал: Дюна (2021) — 7 из 10» |
| Честность | Если погода или каталог недоступны, ответ строится без них; ошибка модели не подменяется выдуманным ответом |

**Типы ответа** (`AgentResponse.type`)

| Тип | Когда |
|---|---|
| `consent` | Первый визит: правила хранения данных |
| `question` | Вопросы онбординга, распознавателя, уточнения |
| `recommendations` | Подборка из трёх фильмов с трассой |
| `feedback_question` | Вопрос об оценке |
| `confirmation` | Подтверждение сохранения или запрос подтверждения удаления |
| `message` | Информационное сообщение, отказ не по теме |
| `error` | Ошибка модели или сервиса |

**Темы, которые распознаватель выясняет:** настроение; свободное время; с кем смотреть; жанровые пожелания и что исключить. Формулировки вопросов — живые, без шаблона; список тем фиксирован.
