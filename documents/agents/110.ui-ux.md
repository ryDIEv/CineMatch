# 110 — UI/UX: диалоговый дизайн

*CineMatch. Модуль ИИ-агентов* | [оглавление модуля](README.md)

Экраны проектирует [модуль интерфейса](../ui/110.ui-ux.md). Модуль агентов отвечает за содержание диалога.

| Принцип | Применение |
|---|---|
| Свободный текст | Пользователь пишет своими словами; агент не предлагает вариантов-кнопок |
| Не переспрашивать | Если в сообщении уже есть ответ (время, настроение), вопрос не задаётся |
| Один вопрос за раз | В сообщении не больше одного вопроса, до подборки — не больше двух вопросов |
| Конкретные объяснения | Объяснение фильма ссылается на сказанное пользователем: «вы просили без ужасов», «на полтора часа» |
| Подтверждение действий | Сохранение оценки и выбора подтверждается: «Записал: Дюна (2021) — 7 из 10» |
| Честность | Если погода или каталог недоступны, ответ строится без них; ошибка модели не подменяется выдуманным ответом |

**Типы ответа** (`AgentResponse.type`)

| Тип | Когда | Формирует |
|---|---|---|
| `consent` | Первый визит: правила хранения данных | Оркестратор |
| `question` | Вопрос онбординга или агента | Оркестратор, агент |
| `recommendations` | Подборка из трёх фильмов с трассой | Агент |
| `feedback_question` | Вопрос об оценке | Агент |
| `confirmation` | Подтверждение сохранения или запрос подтверждения удаления | Агент, оркестратор |
| `message` | Информационное сообщение, отказ не по теме | Агент, оркестратор |
| `error` | Ошибка модели или сервиса | Оркестратор |

**Что агент выясняет перед подбором:** настроение; свободное время; с кем смотреть; жанровые пожелания и что исключить. Формулировки вопросов живые, без шаблона; список тем фиксирован в системном промпте.

### Будущий функционал

Тон и формулировки для напоминаний и подборки новинок.
