# 110 — UI/UX: диалоговый дизайн

*CineMatch. Модуль ИИ-агентов* | [оглавление модуля](README.md)

Экраны проектирует [модуль интерфейса](../ui/110.ui-ux.md). Модуль агентов отвечает за содержание диалога и за дословные тексты, которые формирует код или агент. Тексты ошибок — в [overall/contracts.md §6](../overall/contracts.md#6-ошибки); здесь их нет, кроме ссылок.

## 1. Принципы

| Принцип | Применение |
|---|---|
| Свободный текст | Пользователь пишет своими словами; агент не предлагает кнопок-вариантов |
| Не переспрашивать | Если в сообщении уже есть ответ (время, настроение), вопрос не задаётся |
| Один вопрос за раз | В сообщении не больше одного вопроса; до подборки — не больше двух |
| Конкретные объяснения | Объяснение ссылается на сказанное пользователем: «вы просили без ужасов», «на полтора часа» |
| Подтверждение действий | Сохранение выбора и оценки подтверждается названием и годом |
| Честность | Если погода или каталог недоступны, ответ строится без них; ошибка модели не подменяется выдуманным ответом |
| Один тон | Живой, короткий, без канцелярита; обращение на «вы»; без эмодзи и без markdown |

## 2. Текст согласия

Показывается первым сообщением до любого обращения к модели. Две кнопки: «Принимаю» и «Не сейчас». Текст ниже — нормативный, изменяется только вместе с ADR-033.

```text
CineMatch хранит ваши сообщения, город, историю выборов и оценок — только на этом компьютере, в локальной базе.

Чтобы подобрать фильм, текст сообщения и краткие сведения о ваших вкусах передаются внешнему провайдеру языковой модели (RouterAI); сервер провайдера может находиться за рубежом. Имя, почта и другие данные, по которым вас можно опознать, не передаются.

Фильмы и постеры приходят из TMDB, погода — из Open-Meteo.

Удалить всё можно одной фразой «удали мои данные» или кнопкой в разделе «Мои данные». Без согласия CineMatch не сохраняет данные и не обращается к модели.
```

При отказе показывается тот же текст и строка: «Без согласия я не смогу сохранять данные и обращаться к модели. Если передумаете — нажмите «Принимаю» или напишите «принимаю».»

## 3. Типы ответа

| Тип | Когда | Формирует |
|---|---|---|
| `consent` | Первый визит: правила хранения данных | Оркестратор |
| `question` | Вопрос онбординга или агента | Оркестратор, агент |
| `recommendations` | Подборка от одного до трёх фильмов с трассой | Агент |
| `feedback_question` | Вопрос об оценке | Агент |
| `confirmation` | Подтверждение сохранения или запрос подтверждения удаления | Агент, оркестратор |
| `message` | Информационное сообщение, отказ не по теме | Агент, оркестратор |
| `error` | Ошибка модели или сервиса | Оркестратор |

Прогресс отдельным типом не является: это события SSE, они не входят в `AgentResponse` ([contracts §3](../overall/contracts.md#3-сообщения-о-ходе-работы)).

## 4. Фразы хода работы

`text` события `progress` — готовая фраза без параметров. Набор закрытый; расширение — изменение контракта.

| `step` | Ситуация | Фраза |
|---|---|---|
| `classify` | приём любого сообщения | «Определяю, что вы написали…» |
| `tool` | `extract_context` | «Разбираю, что вы описали…» |
| `tool` | `get_user_ratings`, `get_user_profile` | «Смотрю ваши оценки…» |
| `tool` | `get_weather` | «Проверяю погоду…» |
| `tool` | `find_movies` | «Ищу фильмы…» |
| `tool` | `get_movie_with_credits`, `search_movie` | «Уточняю детали…» |
| `tool` | `save_choice`, `save_rating`, `close_choice` | «Сохраняю…» |
| `check` | после ответа модели | «Проверяю подборку…» |

## 5. Тексты диалога

| Ситуация | Текст | Кто формирует |
|---|---|---|
| Первый визит | правила из раздела 2 | оркестратор |
| Согласие принято | «Напишите город, в котором будете смотреть кино, — учту погоду.» | оркестратор |
| Город найден, один вариант | «Записал: Москва. Что за вечер — устали, есть время?» | оркестратор + агент |
| Несколько городов | «Нашёл несколько вариантов: Казань (Татарстан), Казань (Кемеровская область). Какой ваш?» | оркестратор |
| Город не найден | текст `CITY_NOT_FOUND` из [contracts §6](../overall/contracts.md#6-ошибки) | оркестратор |
| Вопрос о вечере | один вопрос по промпту, например «С кем будете смотреть и есть ли что-то, чего точно не хочется?» | агент |
| Подборка | «За окном дождь — вот три спокойных фильма до полутора часов:» + карточки | агент |
| Найдено меньше трёх | «Подошли только два фильма. Могу ослабить критерии — например, добавить времени. Поискать?» | агент |
| Ничего не найдено | «По этим критериям ничего не нашлось. Можно убрать жанр или расширить время — что важнее?» | агент |
| Подборка отклонена | «Хорошо, в другой раз. Если захотите — просто опишите вечер.» | агент |
| Выбор сохранён | «Хороший выбор на вечер. Приятного просмотра! Когда вернётесь, спрошу, как вам фильм.» | агент |
| Оценка сохранена | «Записал: «Двое и собака» (2016) — 8 из 10.» | агент |
| Оценка не названа | «На сколько из 10? Достаточно одной цифры.» | агент |
| «Не смотрел» | «Понял, убрал из вопросов. Что посмотрим сегодня?» | агент |
| Неоднозначное название | «Нашёл два фильма: 2011 и 1987 года. Какой из них?» | агент |
| Запрос удаления | «Удалить оценки, историю и настройки? Это действие нельзя отменить. Ответьте «да» или «нет».» | оркестратор |
| Вопрос об удалении | «Удалятся оценки, история выборов, город и настройки. Каталог фильмов останется. Ответьте «да» или «нет».» | оркестратор |
| Данные удалены | «Готово, данные удалены.» | оркестратор |
| Отказ от удаления | «Хорошо, оставил как было. Чем помочь с выбором?» | оркестратор |
| Не по теме | «Я помогаю только с выбором фильмов. Расскажите, какое настроение и сколько есть времени, — подберу что-нибудь на вечер.» | оркестратор |
| Небезопасный запрос | «С этим не помогу. Могу подобрать фильм на вечер — расскажите о настроении.» | оркестратор |
| Слишком длинное сообщение | текст `INPUT_TOO_LONG` из [contracts §6](../overall/contracts.md#6-ошибки) | оркестратор |

Правила:

1. Текстов вне этой таблицы, таблицы ошибок и промптов не существует. Если нужна новая фраза — сначала правка документа.
2. Список городов, названия фильмов и годы подставляются из данных, а не пишутся в промпте.
3. Отказ не по теме не предлагает меню и не перечисляет возможности.
4. Ошибка модели не маскируется «примерным» ответом: пользователь видит текст из каталога ошибок.
5. В одном сообщении агента — не больше трёх карточек и не больше одного вопроса.

## 6. Что агент выясняет перед подбором

Настроение; свободное время; с кем смотреть; жанровые пожелания и что исключить. Формулировки живые, без шаблона; список тем фиксирован в промпте ([125 §2](125.prompts.md#2-system_agentmd)). Если тема уже раскрыта в сообщении — вопрос не задаётся.
