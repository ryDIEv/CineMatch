# 075 — NFR

*CineMatch. Модуль ИИ-агентов* | [оглавление модуля](README.md)

| ID | Категория | Требование | Метрика и порог |
|---|---|---|---|
| NFR-AG-01 | Производительность | Ответ на одно сообщение | ≤ 10 с для 95 % сообщений |
| NFR-AG-02 | Производительность | Полный подбор | ≤ 60 с от первого сообщения до трёх фильмов, включая ответы пользователя |
| NFR-AG-03 | Производительность | Классификация запроса | ≤ 2 с |
| NFR-AG-04 | Надёжность | Ошибка модели или сети | Один повтор, затем `AgentResponse(type=error)`; этап диалога не теряется |
| NFR-AG-05 | Надёжность | Невалидный ответ модели | Не более одного повторного запроса; невалидный ответ не показывается пользователю |
| NFR-AG-06 | Безопасность | Вызовы инструментов | 0 вызовов вне списка агента (проверка кодом) |
| NFR-AG-07 | Безопасность | Внедрение инструкций | Системный промпт не раскрывается, инструкции из текста пользователя и описаний фильмов не выполняются; проверка на наборе из 20 атак |
| NFR-AG-08 | Безопасность | Ключ API | Только в `.env`, не попадает в журнал и репозиторий |
| NFR-AG-09 | Приватность | Согласие | До согласия не сохраняется ничего и не вызывается модель |
| NFR-AG-10 | Стоимость | Расход на сообщение | Не более 8 вызовов модели; ≤ 30 000 входных токенов |
| NFR-AG-11 | Сопровождаемость | Промпты | Отдельные файлы в репозитории, изменения через pull request |
| NFR-AG-12 | Сопровождаемость | Смена модели | Через конфигурацию, без изменения кода |
| NFR-AG-13 | Наблюдаемость | Журнал | Каждый вызов модели и инструмента: время, шаг, параметры, длительность, токены |
| NFR-AG-14 | Прозрачность | Трасса решений | Каждая подборка сопровождается трассой; в ней нет системных промптов и ключей |
| NFR-AG-15 | Приватность | Данные в запросах к модели | Нет данных, позволяющих установить личность; история оценок — пары «фильм — оценка» |
| NFR-AG-16 | Качество | Рекомендации вне каталога | 0 на наборе тестовых диалогов (TS-AG-09) |

### Будущий функционал

Время создания напоминания по фразе ≤ 5 с; работа в режиме локальной модели с тем же качеством вызова инструментов (проверяется на тех же сценариях).
