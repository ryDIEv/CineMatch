# Общая часть документации

*Слой, общий для трёх модулей. Здесь лежат значения, которые нельзя описывать трижды.*

| Документ | Что содержит | Кто ведёт |
|---|---|---|
| [contracts.md](contracts.md) | структуры (`MovieCard`, `RecommendedMovie`, `AgentResponse`, `EveningContext`, `SessionState`, `AgentOutput`), коды ошибок, `/start`, согласие, `progress`, пределы | все трое, изменения с одобрением |
| [config.md](config.md) | переменные окружения, тайм-ауты и целевые значения | все трое |
| [build.md](build.md) | структура репозитория, порядок старта, команды, карта «файл → документ», приёмка сборки | все трое |

Техническое задание общей части и модуля ИИ-агентов — [`docs/specs/cinematch_specs_agents.docx`](../../docs/specs/cinematch_specs_agents.docx).

## Правила

1. **Одно значение — один документ.** Поля структур, коды ошибок, тексты ошибок, переменные и тайм-ауты описаны только здесь. Документы модулей (`130`, `165`, `075`, `120`) ссылаются на эти файлы и не повторяют значения.
2. **Изменение контракта** — pull request с одобрением всех трёх ответственных и запись в [145 модуля агентов](../agents/145.architecture-decisions.md).
3. **Версия** контрактов и правила совместимости — [contracts.md §1](contracts.md#1-правила-версионирования).
4. **Тексты для пользователя** (согласие, отказы, подсказки) — [110 модуля агентов](../agents/110.ui-ux.md); тексты ошибок — [contracts.md §6](contracts.md#6-ошибки). Других текстов в коде нет.
5. **Проверка** — `python scripts/check_docs.py` из корня репозитория; расхождение списка переменных или кодов считается ошибкой сборки.

## Место в комплекте

```
documents/
├── overall/      этот комплект: контракты, конфигурация, сборка
├── agents/       модуль ИИ-агентов (010…165, 125, diagrams/)
├── data/         модуль данных
├── ui/           модуль интерфейса + prototype/
└── rationale.md  обзор, теория, обоснование технологий
```
